Feature: Transaction Delete

FieldValue
Version20261020 V1
DescriptionDelete one transaction by id, applying the non-negative balance rule after the delete.
Depends OnDATABASE.md, FEATURE-Balance-Rule.md, FEATURE-Command-Transaction.md, FEATURE-CLI-Output.md, FEATURE-CLI-Dispatch.md
Providesledger txn delete <id>
Consumestransactions.get, transactions.delete

Purpose

ledger txn delete <id> removes one transaction. On success it prints deleted and the id. An absent id exits 4. A delete that leaves any account below zero exits 3. Every rejected delete changes nothing.

Trigger

The user runs ledger txn delete <id>.

Behavior

  1. Parse <id> as an integer. A non-integer id exits 3 before any lookup.
  2. Within the command transaction, fetch the row by txn_id through transactions.get. An absent

id exits 4.

  1. Remove the row through transactions.delete.
  2. Apply the balance rule to the account the removed row touched (FEATURE-Balance-Rule.md). A

negative balance exits 3 and rolls back the delete.

  1. Commit and print:
deleted
<id>

User Acceptance

  • None.

Guardrails

  • A rejected delete changes no row and prints nothing to standard output.
  • Balance is computed from the database after the delete, never from a cached value.
  • Absent-id and non-integer-id checks run before any write.
