FEATURE: Transaction Get

FieldValue
Version20261020 V1
DescriptionPrint one transaction row by id, rejecting non-integer ids before lookup.
Depends OnDATABASE.md, FEATURE-CLI-Dispatch.md, FEATURE-CLI-Output.md, FEATURE-Amount-Format.md, FEATURE-Command-Transaction.md
Providesledger txn get <id>
Consumestransactions.get

Purpose

ledger txn get <id> prints the stored transaction with the given id.

Behavior

  • The command runs inside one command transaction (FEATURE-Command-Transaction.md).
  • The <id> argument must be a non-integer-free decimal integer. A non-integer id exits 3 before any

lookup (AC-012).

  • The row is read with transactions.get. An absent id exits 4.
  • On success the row is printed through the CSV output contract as:
  txn_id,date,account,category,amount,memo
  <id>,<date>,<account>,<category>,<amount>,<memo>

The amount uses the two-decimal output format.

Programmatic Acceptance

=== AC txn-get-prints-row ===
Intent: Getting an existing transaction prints its row with the two-decimal amount.
Suite: scoped

from cli.testing import cli_runner from persistence.testing import db_session

with db_session() as db: db.accounts.create(account="DRAWER1", name="Front Drawer") db.categories.create(category="SALES", description="Sales receipts") db.transactions.create(txn_id=121, date="2026-04-01", account="DRAWER1", category="SALES", amount=4550, memo="walk in sale") code, out, _ = cli_runner("txn", "get", "121")

assert code == 0 assert out == "txn_id,date,account,category,amount,memo\n121,2026-04-01,DRAWER1,SALES,45.50,walk in sale\n" === END AC txn-get-prints-row ===
