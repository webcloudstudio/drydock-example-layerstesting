FEATURE: Account Add

FieldValue
Version20261020 V1
DescriptionAdd an account with zero transactions and a zero balance through ledger account add <code> <name>.
Depends OnDATABASE.md, FEATURE-Code-Validation.md, FEATURE-Amount-Format.md, FEATURE-Command-Transaction.md, FEATURE-CLI-Output.md, FEATURE-CLI-Dispatch.md
Providesledger account add <code> <name>
Consumesaccounts.create, accounts.get, accounts.list

Purpose

Creates one row in the accounts table and prints it.

Behavior

  • The code must be 1 to 12 characters of A-Z and 0-9. The name must be 1 to 40 characters with no comma or newline. A violation exits 3 and changes nothing.
  • A code already present exits 3 and changes nothing.
  • On success, stdout is the account header row followed by the new row <code>,<name>,0,0.00.
  • The command runs in one command transaction.

Programmatic Acceptance
