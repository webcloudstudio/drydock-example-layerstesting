Feature: Report Balances

FieldValue
Version20261020 V1
DescriptionPrint one balance row per account, ordered by code, then a TOTAL row, all computed from the database.
Depends OnDATABASE.md, FEATURE-Amount-Format.md, FEATURE-Command-Transaction.md, FEATURE-CLI-Output.md, FEATURE-CLI-Dispatch.md
Providesledger report balances
Consumesaccounts.list, transactions.list

Purpose

ledger report balances reports each account's transaction count and balance, followed by a TOTAL row across all accounts.

Trigger

The user runs ledger report balances.

Behavior

  1. Within the command transaction, read every account through accounts.list, ordered by

account ascending.

  1. For each account, compute its transaction count and balance by query. The balance is the sum

of its transaction amounts in integer cents, formatted per FEATURE-Amount-Format.md.

  1. Print the header and one row per account:
account,name,transactions,balance
  1. Print the TOTAL row. Its count is the total number of transactions, and its balance is the sum

of every transaction amount:

TOTAL,,<count>,<sum>
  1. With no accounts, print only TOTAL,,0,0.00 after the header.

No value is embedded as a constant. Every count and sum is derived from a query.

Guardrails

  • No count, sum, or total is hardcoded; every value comes from a query.
  • Amounts are formatted with two decimals, never floating point, and a zero total prints 0.00,

never -0.00.
