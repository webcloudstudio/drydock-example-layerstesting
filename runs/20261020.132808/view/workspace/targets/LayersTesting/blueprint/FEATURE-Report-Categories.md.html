Feature: Report Categories

FieldValue
Version20261020 V1
DescriptionPrint one row per category, including categories with no transactions, ordered by code, then a TOTAL row, all computed from the database.
Depends OnDATABASE.md, FEATURE-Amount-Format.md, FEATURE-Command-Transaction.md, FEATURE-CLI-Output.md, FEATURE-CLI-Dispatch.md
Providesledger report categories
Consumescategories.list, transactions.list

Purpose

ledger report categories reports, for every category, its description, transaction count, inflow, outflow, and net, followed by a TOTAL row.

Trigger

The user runs ledger report categories.

Behavior

  1. Within the command transaction, read every category through categories.list, ordered by

category ascending.

  1. For each category, compute by query over transactions.list:
    • transactions: the number of rows in that category.
    • inflow: the sum of positive amounts, in integer cents.
    • outflow: the sum of the absolute values of negative amounts, in integer cents, printed as a

positive number.

  • net: inflow - outflow.

A category with no transactions reports 0, 0.00, 0.00, 0.00.

  1. Print the header and one row per category:
category,description,transactions,inflow,outflow,net
  1. Print the TOTAL row, whose count, inflow, outflow, and net are summed over every transaction:
TOTAL,,<count>,<inflow>,<outflow>,<net>

Amounts are formatted per FEATURE-Amount-Format.md. No value is embedded as a constant.

User Acceptance

  • None.

Guardrails

  • Every category appears, including those with no transactions.
  • No count, sum, or total is hardcoded; every value comes from a query.
  • Amounts are formatted with two decimals, never floating point; a zero total prints 0.00,

never -0.00.
