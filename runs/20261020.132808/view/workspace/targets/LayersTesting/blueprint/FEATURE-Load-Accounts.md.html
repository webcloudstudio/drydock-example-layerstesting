FEATURE: Load Accounts

FieldValue
Version20261020 V1
DescriptionLoad the accounts CSV all or nothing through ledger load accounts <csv>.
Depends OnDATABASE.md, FEATURE-Code-Validation.md, FEATURE-Command-Transaction.md, FEATURE-CLI-Output.md, FEATURE-CLI-Dispatch.md
Providesledger load accounts <csv>
Consumesaccounts.get, accounts.create

Purpose

Loads the accounts table from a CSV file whose header is account,name.

Behavior

  • The header must equal account,name in that order. Otherwise the command exits 3 and stores nothing.
  • Each code is validated by the code rules. Each name is 1 to 40 characters with no comma or newline. A violation exits 3 and stores nothing.
  • A code repeated within the file, or a code already present, exits 3 and stores nothing.
  • A header-only file loads zero rows and exits 0.
  • On success, stdout is table,loaded then accounts,<rows>.
  • The command runs in one command transaction. An unreadable file exits 1 with no change.

import csv import io import os import sys import tempfile

from cli.testing import cli_runner

os.environ["DATABASE_URL"] = os.path.join(tempfile.mkdtemp(), "ledger.db")

def run(*args): code, out, err = cli_runner(*args) print(out) print(err, file=sys.stderr) return code, out, err

seed_path = "sources/seed_accounts.csv" with open(seed_path, newline="") as handle: seed_header, *seed_rows = list(csv.reader(handle)) assert seed_header == ["account", "name"]

assert run("init")[0] == 0 code, out, err = run("load", "accounts", seed_path) assert code == 0 loaded = list(csv.reader(io.StringIO(out))) assert loaded[0] == ["table", "loaded"] assert loaded[-1] == ["accounts", str(len(seed_rows))]

for account, name in seed_rows: code, out, err = run("account", "get", account) assert code == 0 row = list(csv.reader(io.StringIO(out)))[1] assert row[0] == account assert row[1] == name === END AC load-accounts-seed-round-trip ===
