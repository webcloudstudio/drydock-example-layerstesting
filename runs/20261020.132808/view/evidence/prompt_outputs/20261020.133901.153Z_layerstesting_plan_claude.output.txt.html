# FEATURE: Load Accounts

| Field       | Value |
|-------------|-------|
| Version     | 20261020 V1 |
| Description | Load the accounts CSV all or nothing through `ledger load accounts <csv>`. |
| Depends On  | DATABASE.md, FEATURE-Code-Validation.md, FEATURE-Command-Transaction.md, FEATURE-CLI-Output.md, FEATURE-CLI-Dispatch.md |
| Provides    | ledger load accounts <csv> |
| Consumes    | accounts.get, accounts.create |

## Questions

- None.

## Purpose

Loads the `accounts` table from a CSV file whose header is `account,name`.

## Behavior

- The header must equal `account,name` in that order. Otherwise the command exits 3 and stores nothing.
- Each code is validated by the code rules. Each name is 1 to 40 characters with no comma or newline. A violation exits 3 and stores nothing.
- A code repeated within the file, or a code already present, exits 3 and stores nothing.
- A header-only file loads zero rows and exits 0.
- On success, stdout is `table,loaded` then `accounts,<rows>`.
- The command runs in one command transaction. An unreadable file exits 1 with no change.

## Programmatic Acceptance

# FEATURE: Load Transactions

| Field       | Value |
|-------------|-------|
| Version     | 20261020 V1 |
| Description | Load the transactions CSV all or nothing under the balance rule through `ledger load transactions <csv>`. |
| Depends On  | DATABASE.md, FEATURE-Load-Accounts.md, FEATURE-Load-Categories.md, FEATURE-Balance-Rule.md, FEATURE-Amount-Format.md, FEATURE-Date-Validation.md, FEATURE-Command-Transaction.md, FEATURE-CLI-Output.md, FEATURE-CLI-Dispatch.md |
| Provides    | ledger load transactions <csv> |
| Consumes    | transactions.create, transactions.get, transactions.list, accounts.get, categories.get |

## Questions

- None.

## Purpose

Loads the `transactions` table from a CSV file whose header is `txn_id,date,account,category,amount,memo`. Each file row keeps its own `txn_id`.

## Behavior

- The header must equal the transaction columns in that order. Otherwise the command exits 3 and stores nothing.
- Every row's account and category must already exist. An unknown account or category exits 3.
- Each row's amount, date, and memo are validated by their rules.
- The balance rule is checked for the whole file after its changes and before commit. Any negative balance exits 3.
- Any rejection stores none of the file's rows.
- On success, stdout is `table,loaded` then `transactions,<rows>`.

## Programmatic Acceptance

# FEATURE: Account Get

| Field       | Value |
|-------------|-------|
| Version     | 20261020 V1 |
| Description | Print one account with its transaction count and balance through `ledger account get <code>`. |
| Depends On  | DATABASE.md, FEATURE-Code-Validation.md, FEATURE-Amount-Format.md, FEATURE-Command-Transaction.md, FEATURE-CLI-Output.md, FEATURE-CLI-Dispatch.md |
| Provides    | ledger account get <code> |
| Consumes    | accounts.get, transactions.list |

## Questions

- None.

## Purpose

Reads one row from the `accounts` table and prints it with its derived transaction count and balance.

## Behavior

- On success, stdout is the account header row followed by `<code>,<name>,<transactions>,<balance>`.
- `transactions` counts the account's rows in the transactions table.
- `balance` is the sum of those rows' amounts, formatted with two decimals.
- An absent code exits 4 and prints nothing to standard output.
- The command is read-only: repeated calls return identical output.

## Programmatic Acceptance

=== AC account-get-matches-loaded-seed ===
Intent: After the seed accounts, categories, and transactions load, account get for each seed account returns its name and the seed transaction count, and matches the balances report row.

import csv
import io
import os
import sys
import tempfile

from cli.testing import cli_runner

os.environ["DATABASE_URL"] = os.path.join(tempfile.mkdtemp(), "ledger.db")


def run(*args):
    code, out, err = cli_runner(*args)
    print(out)
    print(err, file=sys.stderr)
    return code, out, err


with open("sources/seed_accounts.csv", newline="") as handle:
    _, *account_rows = list(csv.reader(handle))
with open("sources/seed_transactions.csv", newline="") as handle:
    _, *txn_rows = list(csv.reader(handle))

assert run("init")[0] == 0
assert run("load", "accounts", "sources/seed_accounts.csv")[0] == 0
assert run("load", "categories", "sources/seed_categories.csv")[0] == 0
assert run("load", "transactions", "sources/seed_transactions.csv")[0] == 0

code, out, err = run("report", "balances")
assert code == 0
balances = {row[0]: row for row in list(csv.reader(io.StringIO(out)))[1:]}

for account, name in account_rows:
    expected_count = sum(1 for row in txn_rows if row[2] == account)
    code, out, err = run("account", "get", account)
    assert code == 0
    row = list(csv.reader(io.StringIO(out)))[1]
    assert row[0] == account
    assert row[1] == name
    assert row[2] == str(expected_count)
    assert row == balances[account]
