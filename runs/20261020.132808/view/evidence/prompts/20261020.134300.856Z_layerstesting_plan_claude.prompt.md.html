Feature: Report Monthly

FieldValue
Version20261020 V1
DescriptionPrint one row per calendar month that has transactions, ascending, then a TOTAL row, all computed from the database.
Depends OnDATABASE.md, FEATURE-Amount-Format.md, FEATURE-Command-Transaction.md, FEATURE-CLI-Output.md, FEATURE-CLI-Dispatch.md
Providesledger report monthly
Consumestransactions.list

Questions

  • None.

Purpose

ledger report monthly reports, for each month that has transactions, its transaction count, inflow, outflow, and net, followed by a TOTAL row.

Trigger

The user runs ledger report monthly.

Behavior

  1. Within the command transaction, read every transaction through transactions.list.
  2. Group rows by month, the YYYY-MM prefix of date. Only months that have transactions appear.
  3. For each month, compute by query:
    • transactions: the number of rows in that month.
    • inflow: the sum of positive amounts, in integer cents.
    • outflow: the sum of the absolute values of negative amounts, in integer cents, printed as a

positive number.

  • net: inflow - outflow.
  1. Print the header, then one row per month in ascending YYYY-MM order:
month,transactions,inflow,outflow,net
  1. Print the TOTAL row, whose count, inflow, outflow, and net are summed over every transaction:
TOTAL,<count>,<inflow>,<outflow>,<net>
  1. With no transactions, print only TOTAL,0,0.00,0.00,0.00 after the header.

Amounts are formatted per FEATURE-Amount-Format.md. No value is embedded as a constant.

Routes and Interfaces

ledger report monthlyCLI commandExit 0 on success.

Reads and Writes

OperationAccessRepository operationNotes
List transactionsreadtransactions.listGrouped by month and totalled in code from the query result.
