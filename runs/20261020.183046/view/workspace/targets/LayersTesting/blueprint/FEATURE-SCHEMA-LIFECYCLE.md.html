FEATURE: Schema Lifecycle

FieldValue
Version20261020 V1
DescriptionInitialize the ledger schema and report row counts for all required tables.
Depends OnARCHITECTURE.md, DATABASE.md, FEATURE-CLI-FOUNDATION.md
Providesledger init, ledger count
Consumesaccounts repository, categories repository, transactions repository

Behavior

ledger init drops and recreates accounts, categories, and transactions as an atomic schema reset. It writes nothing to standard output.

ledger count emits the header table,rows, followed by the row counts in this fixed order:

  1. accounts
  2. categories
  3. transactions

A database operational failure returns exit code 1.

Database Interface

  • None — persistence is owned by DATABASE.md.

Programmatic Acceptance

=== AC schema-init-empty ===
Intent: Initialization leaves all three declared tables empty and count reports their state.

import csv import os import tempfile from cli.testing import cli_runner

count_code, count_out, count_err = cli_runner("count") assert count_code == 0 rows = list(csv.reader(count_out.splitlines())) assert len(rows) == 4 assert rows[0] == ["table", "rows"] assert [row[1] for row in rows[1:]] == ["0", "0", "0"] finally: if old is None: os.environ.pop("DATABASE_PATH", None) else: os.environ["DATABASE_PATH"] = old === END AC schema-init-empty ===
