## Persistence Boundary

| Boundary | Rule |
|----------|------|
| Raw storage access | Only the generated `persistence/` package reaches the store. |
| Caller dependency | Features depend on declared access patterns and their DTOs, not on schemas. |
| Implementation | Generated from this file at the DATABASE build step; never written by hand. |
| Money | Amounts are stored as integer cents; no floating point at any layer. |
| Aggregation | Sums, counts, and the next transaction id are computed by services from listed rows. |

## Access Patterns

All patterns are shared: the ledger commands are separate Features that reach the same three
tables, so `DATABASE.md` is the Owner and any Blueprint may cite them.

## Schemas

## `accounts`

| Field | Type | Notes |
|-------|------|-------|
| account | TEXT PK | 1 to 12 characters from A-Z and 0-9 |
| name | TEXT NOT NULL | 1 to 40 characters |

## `categories`

| Field | Type | Notes |
|-------|------|-------|
| category | TEXT PK | 1 to 12 characters from A-Z and 0-9 |
| description | TEXT NOT NULL | 1 to 40 characters |

## `transactions`

| Field | Type | Notes |
|-------|------|-------|
| txn_id | INTEGER PK | Loaded from file, or largest stored id plus one |
| date | TEXT NOT NULL | YYYY-MM-DD |
| account | TEXT NOT NULL REFERENCES accounts(account) | Owning account |
| category | TEXT NOT NULL REFERENCES categories(category) | Category code |
| amount | INTEGER NOT NULL | Integer cents, never zero, negative for outflow |
| memo | TEXT NOT NULL DEFAULT '' | 0 to 60 characters |

- INDEX (account, date)

=== AC accounts-list ===
Intent: accounts.list returns created accounts in ascending code order and honors the account filter.

from persistence.testing import db_session

first = "UTACC3A"
second = "UTACC3B"
with db_session() as db:
    db.accounts.create(account=second, name="List B")
    db.accounts.create(account=first, name="List A")
    rows = db.accounts.list()
    codes = [r.account for r in rows]
    assert first in codes and second in codes
    assert codes.index(first) < codes.index(second)
    assert codes == sorted(codes)
    filtered = db.accounts.list(account=first)
    assert [r.account for r in filtered] == [first]
=== END AC accounts-list ===

## Guardrails

- Only the generated `persistence/` package reaches the store; application code never imports a database driver.
- Amounts are integer cents in every column, DTO, and caller; floating point is never used for money.
- No aggregate, report row, count, or total is stored or declared as a repository operation; services compute them from listed rows.
- The schema is built once at the DATABASE step; no command issues DDL.
