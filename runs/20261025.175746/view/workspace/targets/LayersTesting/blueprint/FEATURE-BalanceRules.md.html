FEATURE: Balance Rules

FieldValue
Version20261025 V1
DescriptionAccount summaries and the non-negative balance check used by every mutating command.
Depends OnFEATURE-CliFoundation.md, DATABASE.md
Providescli.balance.account_summary, cli.balance.balances, cli.balance.check_balances, cli.balance.next_txn_id
Consumestransactions.list, accounts.get

Purpose

An account's balance is the sum of its transaction amounts. No command may leave a balance below zero. This module computes balances from stored rows in integer cents and applies the rule before a command writes, so a violation changes nothing.

Interface

FunctionContract
account_summary(db, code) -> tuple[int, int]Transaction count and balance in cents for the account, computed from its stored transactions; (0, 0) when it has none.
balances(db) -> dict[str, int]Balance in cents per account that has transactions.
check_balances(db, deltas)deltas maps account code to the net change in cents the command would make. Raises Rejected (exit 3) when any stored balance plus its delta is below zero; returns None otherwise. Writes nothing.
next_txn_id(db) -> intOne more than the largest stored txn_id, or 1 when the table is empty.

Commands express a post as {account: amount}, an amend as {account: new - old}, a delete as {account: -amount}, a transfer as both sides, and a load as the per-account sum of the file. A balance of exactly zero is allowed. Computation is service-side from listed rows (decision Q-002).

Database Interface

  • FEATURE-TRANSACTIONS-003 — read: list transactions for balances and the largest id - supplies: account - returns: txn_id, account, amount
  • FEATURE-ACCOUNTS-002 — read: confirm an account exists - supplies: account - returns: account, name

from persistence.testing import db_session from cli.balance import balances

acct_a = "UTBAL3A" acct_b = "UTBAL3B" cat = "UTBALC3" with db_session() as db: db.accounts.create(account=acct_a, name="A") db.accounts.create(account=acct_b, name="B") db.categories.create(category=cat, description="Cat") plan = [(980011, acct_a, 500), (980012, acct_a, -200), (980013, acct_b, 75)] for txn_id, acct, cents in plan: db.transactions.create( txn_id=txn_id, date="2026-04-02", account=acct, category=cat, amount=cents, memo="" ) result = balances(db) assert result[acct_a] == sum(c for _, a, c in plan if a == acct_a) assert result[acct_b] == sum(c for _, a, c in plan if a == acct_b) === END AC balancerules-balances ===

from persistence.testing import db_session from cli.balance import check_balances from cli.errors import Rejected
