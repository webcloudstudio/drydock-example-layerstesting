FEATURE: Report Monthly

FieldValue
Version20261025 V1
DescriptionImplements ledger report monthly, which prints inflow, outflow, and net per calendar month computed from stored transactions.
Depends OnARCHITECTURE.md, DATABASE.md, FEATURE-CliFoundation.md
Providesledger report monthly
Consumestransactions.list

Purpose

ledger report monthly summarizes cash movement by month. Every value is computed at run time from the stored transactions; no row, count, or total is embedded.

Trigger

./ledger report monthly with no further arguments.

Behavior

  1. List all transactions through transactions.list (no account filter).
  2. Group by the YYYY-MM prefix of date.
  3. For each month that has at least one transaction, in ascending month order, compute in integer cents:
    • transactions: the number of transactions in the month
    • inflow: sum of positive amounts
    • outflow: sum of absolute values of negative amounts, written as a positive number
    • net: inflow - outflow
  4. Write the header month,transactions,inflow,outflow,net, one row per month, then TOTAL,<count>,<inflow>,<outflow>,<net> summed over all transactions.
  5. Amounts are written with exactly two decimal places, a leading - when negative, and no thousands separator. No floating point is used.
  6. Months with no transactions are omitted. With no transactions at all, only the header and a zero TOTAL row are written.

=== AC report-monthly-rows ===
Intent: The monthly report computes count, inflow, outflow, and net for a month from stored rows and places the month row in ascending order before TOTAL.

import csv import io from decimal import Decimal

from cli.testing import cli_runner from persistence.testing import db_session

acct = "UTRMA1" cat = "UTRMC1" early = "2098-05" late = "2098-06" early_amounts = [10000, -2550] late_amounts = [4001] with db_session() as db: db.accounts.create(account=acct, name="Monthly Probe") db.categories.create(category=cat, description="Monthly Probe") next_id = 920001 for month, amounts in ((early, early_amounts), (late, late_amounts)): for cents in amounts: db.transactions.create( txn_id=next_id, date=month + "-10", account=acct, category=cat, amount=cents, memo="m", ) next_id += 1 code, out, err = cli_runner("report", "monthly") print(out) print(err) assert code == 0 rows = list(csv.reader(io.StringIO(out))) assert rows[0] == ["month", "transactions", "inflow", "outflow", "net"] assert rows[-1][0] == "TOTAL" body = rows[1:-1] months = [r[0] for r in body] assert months == sorted(months) by_month = {r[0]: r for r in body} for month, amounts in ((early, early_amounts), (late, late_amounts)): row = by_month[month] inflow = sum(a for a in amounts if a > 0) outflow = sum(-a for a in amounts if a < 0) assert int(row[1]) == len(amounts) assert Decimal(row[2]) == Decimal(inflow) / 100 assert Decimal(row[3]) == Decimal(outflow) / 100 assert Decimal(row[4]) == Decimal(inflow - outflow) / 100 for cell in row[2:]: assert len(cell.split(".")[1]) == 2 === END AC report-monthly-rows ===
