FEATURE: CLI Foundation

FieldValue
Version20261025 V1
DescriptionThe ledger executable, command dispatch, exit-code mapping, CSV output, and shared input validators.
Depends OnDATABASE.md, ARCHITECTURE.md
Providesledger, cli.main, cli.testing.cli_runner, cli.errors, cli.validate, cli.money, cli.output, cli.registry

Purpose

Provide the executable and the shared machinery every command uses, so command stories write only their own behavior.

Interface

ModuleContract
ledgerExecutable at the application root; runs cli.main(sys.argv[1:]) and exits with the result.
cli/__init__.py`main(argv: list[str] \None = None) -> int`.
cli/testing.pycli_runner(*args) -> (exit_code, stdout, stderr) without spawning a process.
cli/errors.pyLedgerError with an exit_code attribute; subclasses Operational (1), Usage (2), Rejected (3), NotFound (4).
cli/registry.pyregister(path, min_args, max_args, handler) and COMMANDS. A handler is run(db, args) -> list[list[str]] returning the header and data rows.
cli/commands/Every module is imported at startup; each registers its handlers.
cli/database.pyopen_ledger() opens the store with open_database, using DATABASE_URL, then DATABASE_PATH, then data/app.db.
cli/validate.pyvalidate_code, validate_name, validate_memo, validate_date; each returns the value or raises Rejected.
cli/money.pyparse_amount(text) -> int cents and format_amount(cents) -> str, integer arithmetic only.
cli/output.pywrite_rows(rows) writes comma-separated rows with \n endings and no quoting; TRANSACTION_HEADER, format_transaction(row).

Behavior

  • The dispatcher resolves the command path and checks the argument count before opening the

database. An unknown command, unknown table or report, or wrong argument count exits 2.

  • A LedgerError is mapped to its exit code; the message goes to standard error as one line and

nothing is written to standard output. Any other database failure exits 1.

  • Output is written only after the handler returns, so a failing command writes nothing to

standard output.

  • Codes are 1 to 12 characters from A-Z and 0-9. Names are 1 to 40 characters. Memos are 0 to

60 characters. None contains a comma or newline. Dates are real calendar dates YYYY-MM-DD.

  • Amounts match -?DIGITS[.D[D]], never zero. Output amounts have exactly two decimals, a leading

- when negative, and no thousands separator.

  • A non-integer transaction id is rejected with exit 3 (disclosed decision Q-003).

Database Interface

  • None — persistence is owned by DATABASE.md.

User Acceptance

  • None.

Guardrails

  • Diagnostics go to standard error and are never compared; standard output carries only CSV.
  • A failing command writes nothing to standard output.
  • No floating point is used for money.
  • No database driver is imported outside the shipped persistence library.
