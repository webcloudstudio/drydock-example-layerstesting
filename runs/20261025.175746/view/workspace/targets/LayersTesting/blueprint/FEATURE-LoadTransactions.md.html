FEATURE: Load Transactions

FieldValue
Version20261025 V1
DescriptionImplements ledger load transactions <csv> keeping file txn_ids, with all-or-nothing validation and balance checking.
Depends OnARCHITECTURE.md, DATABASE.md, FEATURE-CliFoundation.md, FEATURE-BalanceRules.md, FEATURE-LoadAccounts.md, FEATURE-LoadCategories.md
Providesledger load transactions
Consumestransactions.create, transactions.get, accounts.get, categories.get, check_balances

Purpose

Bulk-load transactions from a CSV file whose header is exactly txn_id,date,account,category,amount,memo. Each loaded row keeps the txn_id from its file. The command checks every row and the resulting balances before its first write.

Trigger

./ledger load transactions <csv>

Sequence

  1. Reject a wrong argument count with exit 2.
  2. Read the file. An unreadable file exits 1.
  3. Require the exact header; any other header exits 3.
  4. Validate every row: txn_id is an integer; the date is a real calendar date YYYY-MM-DD; the

amount matches -?DIGITS[.D[D]], has at most two decimals, and is never zero; the memo is 0 to 60 characters with no comma or newline. Amounts are parsed to integer cents without floating point.

  1. Reject (exit 3) a txn_id repeated within the file or already stored, an account absent from

accounts, and a category absent from categories.

  1. Apply the whole file to the stored balances through check_balances; if any account balance

would be below zero after the file is applied, exit 3 (Decision Q-004: final balances are checked).

  1. Only then write all rows through transactions.create, keeping each file txn_id.
  2. Print table,loaded and transactions,<rows>.

A failing command writes nothing to standard output and one diagnostic line to standard error.

Reads

  • transactions.get, accounts.get, categories.get for validation; stored transactions via check_balances.

Writes

  • transactions.create once per validated row, after all validation has passed.

Database Interface

  • FEATURE-TRANSACTIONS-001 — write: create a transaction - supplies: txn_id, date, account, category, amount, memo - returns: txn_id, date, account, category, amount, memo
  • FEATURE-TRANSACTIONS-002 — read: find a stored transaction by id - supplies: txn_id - returns: txn_id, account, amount
  • FEATURE-ACCOUNTS-002 — read: find a stored account by code - supplies: account - returns: account
  • FEATURE-CATEGORIES-002 — read: find a stored category by code - supplies: category - returns: category

Programmatic Acceptance

=== AC load-transactions-valid ===
Intent: A valid transactions file keeps its txn_ids, stores integer cents, and reports the loaded count.

import csv import io import os import tempfile from cli.testing import cli_runner from persistence.testing import db_session

def dollars(c): return ("-" if c < 0 else "") + str(abs(c) // 100) + "." + format(abs(c) % 100, "02d")

acct = "UTMA1" cat = "UTMC1" rows = [ (910001, "2026-05-01", 10000, "opening"), (910002, "2026-05-02", -2550, "spend"), (910007, "2026-05-03", 475, "gap id kept"), ] with tempfile.TemporaryDirectory() as tmp: path = os.path.join(tmp, "txns.csv") with open(path, "w", newline="") as fh: w = csv.writer(fh, lineterminator="\n") w.writerow(["txn_id", "date", "account", "category", "amount", "memo"]) for txn_id, when, cents, memo in rows: w.writerow([txn_id, when, acct, cat, dollars(cents), memo]) with db_session() as db: db.accounts.create(account=acct, name="Load Txn") db.categories.create(category=cat, description="Load Txn") code, out, err = cli_runner("load", "transactions", path) print(out) print(err) assert code == 0 parsed = list(csv.reader(io.StringIO(out))) assert parsed == [["table", "loaded"], ["transactions", str(len(rows))]] for txn_id, when, cents, memo in rows: stored = db.transactions.get(txn_id=txn_id) assert stored is not None assert stored.date == when assert stored.account == acct assert stored.category == cat assert stored.amount == cents assert isinstance(stored.amount, int) assert stored.memo == memo === END AC load-transactions-valid ===

Guardrails
