Purpose

ledger is a single-executable command-line cash ledger. It keeps accounts, categories, and cash transactions in a relational database reached only through the shipped persistence library, rejects a failing command before it writes, enforces non-negative balances, and reports balances, category totals, and monthly totals. All values come from queries; no report row, count, or total is embedded.

Callers use db.<table>.<operation>(...) as declared in DATABASE.md. SQL, sessions, table names, and column names never cross that boundary, and no command issues DDL.

Technical Decisions

  • Money is integer cents at every layer; floating point is never used. Parsing and formatting use

integer arithmetic only.

  • Every command validates its full input and every business rule before its first write.
  • Sums, counts, balances, and the next transaction id are computed by services from listed rows.
  • Standard output carries only CSV (\n endings, no quoting); diagnostics go to standard error.
  • Exit codes: 0 success, 1 operational, 2 usage, 3 rejected, 4 not found.
  • Commands register themselves in a registry; the dispatcher checks arity before opening the database.
