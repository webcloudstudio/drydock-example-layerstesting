FEATURE: Report Balances

FieldValue
Version20261025 V1
DescriptionImplements ledger report balances, the per-account transaction count and balance with a TOTAL row.
Depends OnARCHITECTURE.md, DATABASE.md, FEATURE-CliFoundation.md, FEATURE-BalanceRules.md
Providesledger report balances
Consumesaccounts.list, transactions.list, account_summary

Purpose

Report each account's transaction count and balance, computed from stored rows in integer cents.

Trigger

./ledger report balances

Sequence

  1. List accounts through accounts.list (ordered by code).
  2. For each account compute the transaction count and the balance (sum of amounts, in cents) from

transactions.list via account_summary.

  1. Print the header account,name,transactions,balance, one row per account ordered by code, then

TOTAL,,<count>,<sum> where count and sum cover every account.

  1. Amounts print with exactly two decimal places, a leading - when negative, and no thousands separator.
  2. Any argument beyond balances is a usage error (exit 2).

Reads

  • accounts.list, transactions.list.

Writes

  • None.

Database Interface

  • FEATURE-ACCOUNTS-003 — read: list accounts in code order - supplies: account - returns: account, name
  • FEATURE-TRANSACTIONS-003 — read: list transactions for an account - supplies: account - returns: txn_id, account, amount

=== AC report-balances-reflects-changes ===
Intent: The report is recomputed from stored rows, so a later transaction changes the balance by exactly its amount.

import csv import io import re from decimal import Decimal from cli.testing import cli_runner from persistence.testing import db_session

def to_cents(text): assert re.fullmatch(r"-?\d+\.\d{2}", text) return int(Decimal(text) * 100)

def balance_of(out, account): rows = list(csv.reader(io.StringIO(out))) return {r[0]: r for r in rows[1:]}[account]

acct = "UTRD1" cat = "UTRDC" first = 8000 second = 1234 with db_session() as db: db.accounts.create(account=acct, name="Moves") db.categories.create(category=cat, description="Bal") db.transactions.create( txn_id=920201, date="2026-05-01", account=acct, category=cat, amount=first, memo="" ) code, out, err = cli_runner("report", "balances") assert code == 0 before = to_cents(balance_of(out, acct)[3]) assert before == first db.transactions.create( txn_id=920202, date="2026-05-02", account=acct, category=cat, amount=second, memo="" ) code, out, err = cli_runner("report", "balances") assert code == 0 row = balance_of(out, acct) assert to_cents(row[3]) == before + second assert int(row[2]) == 2 === END AC report-balances-reflects-changes ===
