FEATURE: Load Accounts

FieldValue
Version20261025 V1
DescriptionImplements ledger load accounts <csv> with all-or-nothing validation of the whole file.
Depends OnARCHITECTURE.md, DATABASE.md, FEATURE-CliFoundation.md
Providesledger load accounts
Consumesaccounts.create, accounts.get

Purpose

Bulk-load accounts from a CSV file whose header is exactly account,name. The command checks every row and every rule before its first write, so a file with one invalid row stores nothing.

Trigger

./ledger load accounts <csv>

Sequence

  1. Reject a wrong argument count or an unknown table with exit 2.
  2. Read the file. An unreadable file exits 1.
  3. Require the header account,name; any other header exits 3.
  4. Validate every data row: the code is 1 to 12 characters from A-Z and 0-9; the name is 1 to

40 characters with no comma or newline; a row with the wrong number of fields is invalid.

  1. Reject (exit 3) a code that repeats within the file or already exists in accounts.
  2. Only after every row passed, write all rows through accounts.create.
  3. Print table,loaded and accounts,<rows> as CSV with \n endings.

A failing command writes nothing to standard output and one diagnostic line to standard error.

Reads

  • accounts.get for each code in the file, to detect duplicates with stored rows.

Writes

  • accounts.create once per validated row, after all validation has passed.

Database Interface

  • FEATURE-ACCOUNTS-001 — write: create an account - supplies: account, name - returns: account, name
  • FEATURE-ACCOUNTS-002 — read: find a stored account by code - supplies: account - returns: account, name

Programmatic Acceptance

=== AC load-accounts-valid ===
Intent: A valid accounts file loads, reports the loaded count, and every row reads back from the store.

import csv import io import os import tempfile from cli.testing import cli_runner from persistence.testing import db_session

rows = [["UTLA1", "Load One"], ["UTLA2", "Load Two"], ["UTLA3", "Load Three"]] with tempfile.TemporaryDirectory() as tmp: path = os.path.join(tmp, "accounts.csv") with open(path, "w", newline="") as fh: w = csv.writer(fh, lineterminator="\n") w.writerow(["account", "name"]) w.writerows(rows) with db_session() as db: code, out, err = cli_runner("load", "accounts", path) print(out) print(err) assert code == 0 parsed = list(csv.reader(io.StringIO(out))) assert parsed == [["table", "loaded"], ["accounts", str(len(rows))]] for account, name in rows: stored = db.accounts.get(account=account) assert stored is not None assert stored.name == name === END AC load-accounts-valid ===

import csv import os import tempfile from cli.testing import cli_runner from persistence.testing import db_session

stored_code = "UTLD1" fresh = "UTLD2" repeated = "UTLD3" with tempfile.TemporaryDirectory() as tmp: with db_session() as db: db.accounts.create(account=stored_code, name="Already Here")

Guardrails

  • Validate every row and rule before the first write; a rejected load changes nothing.
  • Do not read sources/ seed files from application code; they reach the database only through this command.
  • Open no database driver outside the shipped persistence library.
  • Diagnostics go to standard error only and are never compared.
