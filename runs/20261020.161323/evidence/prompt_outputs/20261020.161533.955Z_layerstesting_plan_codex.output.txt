# FEATURE: Balance Reports

| Field       | Value |
|-------------|-------|
| Version     | 20261020 V1 |
| Description | Reports persisted account balances, transaction counts, and ledger totals. |
| Depends On  | ARCHITECTURE.md, DATABASE.md, FEATURE-Accounts.md, FEATURE-Transaction-Posting.md, FEATURE-Transaction-Mutation.md, FEATURE-Transfers.md |
| Provides    | ledger report balances |
| Consumes    | `accounts.list`, `transactions.list` |

## Questions

- None.

## Purpose

The balances report reads every account and its persisted transactions, orders accounts by code, formats balances as decimal currency, and appends a database-derived total row.

## Workflow

`ledger report balances` emits the header, one row per account ordered by account code, and `TOTAL,,<transaction count>,<sum>`.

Empty ledgers still emit the header and zero-valued total row.

## Programmatic Acceptance

=== AC balances-report-round-trip ===
Intent: The balances command reports accounts, counts, balances, and a total from persisted state.

from cli.testing import cli_runner

code, _, _ = cli_runner("init")
assert code == 0

account_code = "REPORT1"
account_name = "Report Drawer"
category_code = "SALES"
amount = "12.34"
date = "2026-04-01"

code, _, _ = cli_runner("load", "accounts", "sources/seed_accounts.csv")
assert code == 0

code, _, _ = cli_runner("load", "categories", "sources/seed_categories.csv")
assert code == 0

code, _, _ = cli_runner("account", "add", account_code, account_name)
assert code == 0

code, _, _ = cli_runner("txn", "post", account_code, category_code, amount, date)
assert code == 0

code, stdout, _ = cli_runner("report", "balances")
assert code == 0
rows = stdout.splitlines()
assert rows[0] == "account,name,transactions,balance"
assert any(row.startswith(f"{account_code},{account_name},1,") for row in rows)
assert rows[-1].startswith("TOTAL,,")
=== END AC balances-report-round-trip ===

=== AC balances-report-empty ===
Intent: An initialized empty ledger produces a valid zero-row balances report.

from cli.testing import cli_runner

code, _, _ = cli_runner("init")
assert code == 0

code, stdout, _ = cli_runner("report", "balances")
assert code == 0
rows = stdout.splitlines()
assert rows[0] == "account,name,transactions,balance"
assert rows[-1] == "TOTAL,,0,0.00"
=== END AC balances-report-empty ===

## User Acceptance

- None.

## Guardrails

- Compute every value from persisted queries; do not hardcode report rows or totals.
- Use integer cents for all aggregation and format currency only at the CLI boundary.
- Emit accounts ordered by account code and include the total row.

# FEATURE: Category Reports

| Field       | Value |
|-------------|-------|
| Version     | 20261020 V1 |
| Description | Reports persisted transaction totals for every category, including unused categories. |
| Depends On  | ARCHITECTURE.md, DATABASE.md, FEATURE-Transaction-Posting.md |
| Provides    | ledger report categories |
| Consumes    | `categories.list`, `transactions.list` |

## Questions

- None.

## Purpose

The category report aggregates transactions by category while retaining categories with no transactions. It reports transaction count, inflow, outflow, and net values in integer cents formatted as currency.

## Workflow

`ledger report categories` emits categories ordered by code followed by a database-derived `TOTAL` row.

## Programmatic Acceptance

Intent: The category report includes unused categories and derives totals from persisted transactions.

assert code == 0

code, _, _ = cli_runner("load", "categories", "sources/seed_categories.csv")
assert code == 0

code, _, _ = cli_runner("txn", "post", "DRAWER1", "SALES", "25.00", "2026-04-01")
assert code == 0

code, stdout, _ = cli_runner("report", "categories")
assert code == 0
rows = stdout.splitlines()
assert rows[0] == "category,description,transactions,inflow,outflow,net"

=== END AC category-report-includes-unused ===

- Compute inflow, outflow, and net from integer-cent transaction amounts.
- Order category rows by category code and derive the total row from queried data.

# FEATURE: Monthly Reports

| Field       | Value |
|-------------|-------|
| Version     | 20261020 V1 |
| Description | Reports persisted transaction totals grouped by calendar month. |
| Depends On  | ARCHITECTURE.md, DATABASE.md, FEATURE-Transaction-Posting.md |
| Provides    | ledger report monthly |
| Consumes    | `transactions.list` |

## Questions

- None.

## Purpose

The monthly report groups transactions by their `YYYY-MM` calendar month, omits months without transactions, orders rows ascending, and appends a database-derived total.

## Workflow

`ledger report monthly` emits the monthly header, transaction-bearing months only, and a `TOTAL` row.

## Programmatic Acceptance

=== AC monthly-report-grouping ===
Intent: The monthly report groups persisted transactions by month and computes signed totals.

from cli.testing import cli_runner

code, _, _ = cli_runner("init")
assert code == 0

code, _, _ = cli_runner("load", "accounts", "sources/seed_accounts.csv")
assert code == 0

code, _, _ = cli_runner("load", "categories", "sources/seed_categories.csv")
assert code == 0

first_amount = "10.00"
second_amount = "-3.25"
first_date = "2026-04-01"
second_date = "2026-06-02"

code, _, _ = cli_runner("txn", "post", "DRAWER1", "SALES", first_amount, first_date)
assert code == 0
code, _, _ = cli_runner("txn", "post", "DRAWER1", "SUPPLY", second_amount, second_date)
assert code == 0

code, stdout, _ = cli_runner("report", "monthly")
assert code == 0
rows = stdout.splitlines()
assert rows[0] == "month,transactions,inflow,outflow,net"
assert rows[1] == "2026-04,1,10.00,0.00,10.00"
assert rows[2] == "2026-06,1,0.00,3.25,-3.25"
assert rows[-1] == "TOTAL,2,10.00,3.25,6.75"
=== END AC monthly-report-grouping ===

=== AC monthly-report-empty ===
Intent: An initialized ledger with no transactions reports no month rows and a zero total.

from cli.testing import cli_runner

code, _, _ = cli_runner("init")
assert code == 0

code, stdout, _ = cli_runner("report", "monthly")
assert code == 0
rows = stdout.splitlines()
assert rows[0] == "month,transactions,inflow,outflow,net"
assert rows[-1] == "TOTAL,0,0.00,0.00,0.00"
assert len(rows) == 2
=== END AC monthly-report-empty ===

## User Acceptance

- None.

## Guardrails

- Group by the transaction date's `YYYY-MM` value.
- Omit months with no transactions and order remaining months ascending.
- Perform aggregation in integer cents and format only final output values.
