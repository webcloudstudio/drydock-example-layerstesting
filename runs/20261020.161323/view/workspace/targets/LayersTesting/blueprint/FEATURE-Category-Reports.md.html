FEATURE: Category Reports

FieldValue
Version20261020 V1
DescriptionReports persisted transaction totals for every category, including unused categories.
Depends OnARCHITECTURE.md, DATABASE.md, FEATURE-Transaction-Posting.md
Providesledger report categories
Consumescategories.list, transactions.list

Purpose

The category report aggregates transactions by category while retaining categories with no transactions. It reports transaction count, inflow, outflow, and net values in integer cents formatted as currency.

Workflow

ledger report categories emits categories ordered by code followed by a database-derived TOTAL row.

Programmatic Acceptance

=== AC category-report-includes-unused ===
Intent: The category report includes unused categories and derives totals from persisted transactions.

from cli.testing import cli_runner

code, _, _ = cli_runner("init") assert code == 0

code, _, _ = cli_runner("load", "accounts", "sources/seed_accounts.csv") assert code == 0

code, _, _ = cli_runner("txn", "post", "DRAWER1", "SALES", "25.00", "2026-04-01") assert code == 0

code, stdout, _ = cli_runner("report", "categories") assert code == 0 rows = stdout.splitlines() assert rows[0] == "category,description,transactions,inflow,outflow,net" assert any(row.startswith("SALES,Sales receipts,") for row in rows) assert any(row.startswith("OPENING,Opening balance,0,0.00,0.00,0.00") for row in rows) assert rows[-1].startswith("TOTAL,,") === END AC category-report-includes-unused ===
