FEATURE: Load Transactions

FieldValue
Version20261027 V1
DescriptionImplements ledger load transactions <csv> with full validation and the balance rule checked before any write.
Depends OnFEATURE-LoadCsvReader.md, FEATURE-Validation.md, FEATURE-BalanceRule.md, FEATURE-LoadAccounts.md, FEATURE-LoadCategories.md, DATABASE.md
Providesledger load transactions
Consumesledger_core.csvio, ledger_core.validation, ledger_core.balances, cli.registry

Purpose

Load transactions from a CSV file whose header is txn_id,date,account,category,amount,memo. Each row keeps the txn_id from the file. The file is accepted entirely or not at all.

Behavior

  1. ledger load transactions <csv> takes exactly one file argument; other counts exit 2.
  2. Read the file with ledger_core.csvio.read_rows(path, ("txn_id", "date", "account", "category", "amount", "memo")).

An unreadable file exits 1; a wrong header or wrong field count exits 3.

  1. Validate every row before any write: txn_id is an integer, not repeated in the file and not

already stored; the date is a real calendar date YYYY-MM-DD; the account and category exist in the store; the amount matches -?DIGITS[.D[D]], has at most two decimals, and is not zero; the memo is 0 to 60 characters with no comma or newline. Amounts are converted to integer cents without floating point.

  1. Apply ledger_core.balances.check_no_negative to all rows together as inserts. The effect of

the whole file is considered at once, so a withdrawal that precedes its funding deposit in the file is accepted when the final balance is not below zero. A resulting negative balance for any account rejects the file.

  1. Insert every row in one atomic unit, then print table,loaded and transactions,<rows>.
  2. Any rejection exits 3, writes nothing to standard output, and stores none of the rows.

Database Interface

  • FEATURE-ACCOUNT-002 — read: confirm each referenced account exists - supplies: account - returns: account
  • FEATURE-CATEGORY-002 — read: confirm each referenced category exists - supplies: category - returns: category
  • FEATURE-TXN-002 — read: detect an already stored txn_id - supplies: txn_id - returns: txn_id
  • FEATURE-TXN-001 — write: create a transaction - supplies: txn_id, date, account, category, amount, memo - returns: txn_id, date, account, category, amount, memo

=== AC load-transactions-success ===
Intent: a valid file loads every row keeping its txn_id, prints the declared two CSV rows, and each stored row reads back with the cents derived from the input text.
Requires: executable=python3; scope=test

import csv import io import os import tempfile from decimal import Decimal from cli.testing import cli_runner from persistence.testing import db_session

acct, cat = "ZZMA1", "ZZMC1" rows = [ ["920000001", "2026-01-02", acct, cat, "100.50", "deposit"], ["920000002", "2026-01-03", acct, cat, "-20.25", "withdrawal"], ["920000003", "2026-01-04", acct, cat, "7", ""], ] with tempfile.TemporaryDirectory() as d: path = os.path.join(d, "txns.csv") with open(path, "w", newline="") as fh: w = csv.writer(fh, lineterminator="\n") w.writerow(["txn_id", "date", "account", "category", "amount", "memo"]) w.writerows(rows) with db_session() as db: db.accounts.create(account=acct, name="Load Txn Account") db.categories.create(category=cat, description="Load Txn Category") code, out, err = cli_runner("load", "transactions", path) print(out, err) assert code == 0 parsed = list(csv.reader(io.StringIO(out))) assert parsed == [["table", "loaded"], ["transactions", str(len(rows))]] for tid, day, a, c, amt, memo in rows: row = db.transactions.get(txn_id=int(tid)) assert row is not None g = (lambda n: row[n]) if isinstance(row, dict) else (lambda n: getattr(row, n)) assert g("date") == day assert g("account") == a assert g("category") == c assert g("amount") == int(Decimal(amt) * 100) assert g("memo") == memo === END AC load-transactions-success ===
