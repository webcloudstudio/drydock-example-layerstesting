FEATURE: Load Accounts

FieldValue
Version20261027 V1
DescriptionImplements ledger load accounts <csv> as an all-or-nothing bulk load.
Depends OnFEATURE-LoadCsvReader.md, FEATURE-Validation.md, DATABASE.md
Providesledger load accounts
Consumesledger_core.csvio, ledger_core.validation, cli.registry

Purpose

Load accounts from a CSV file whose header is account,name. Every row is validated before the first write; the rows are then written together or not at all.

Behavior

  1. ledger load accounts <csv> takes exactly one file argument; other counts exit 2.
  2. Read the file with ledger_core.csvio.read_rows(path, ("account", "name")). An unreadable file

exits 1; a wrong header or wrong field count exits 3.

  1. Validate every row before any write: the code is 1 to 12 characters of A-Z0-9, the name is 1

to 40 characters with no comma or newline, the code does not repeat within the file, and the code is not already stored.

  1. Insert every row in one atomic unit. A failure at any row leaves every earlier row unstored.
  2. Print table,loaded then accounts,<rows>, where <rows> is the number of rows inserted.
  3. Any rejection exits 3 with nothing on standard output and one diagnostic line on standard error.

A header-only file loads zero rows and prints accounts,0.

Database Interface

  • FEATURE-ACCOUNT-005 — read: list stored accounts to detect duplicate keys - supplies: — - returns: account, name
  • FEATURE-ACCOUNT-001 — write: create an account - supplies: account, name - returns: account, name

=== AC load-accounts-success ===
Intent: a valid accounts file loads every row, prints the declared two CSV rows with the loaded count, and the rows are readable afterward.
Requires: executable=python3; scope=test

import csv import io import os import tempfile from cli.testing import cli_runner from persistence.testing import db_session

rows = [["ZZLAA1", "Load One"], ["ZZLAA2", "Load Two"], ["ZZLAA3", "Load Three"]] with tempfile.TemporaryDirectory() as d: path = os.path.join(d, "accounts.csv") with open(path, "w", newline="") as fh: w = csv.writer(fh, lineterminator="\n") w.writerow(["account", "name"]) w.writerows(rows) with db_session() as db: code, out, err = cli_runner("load", "accounts", path) print(out, err) assert code == 0 parsed = list(csv.reader(io.StringIO(out))) assert parsed == [["table", "loaded"], ["accounts", str(len(rows))]] for acct, name in rows: row = db.accounts.get(account=acct) assert row is not None got = row["name"] if isinstance(row, dict) else row.name assert got == name === END AC load-accounts-success ===
