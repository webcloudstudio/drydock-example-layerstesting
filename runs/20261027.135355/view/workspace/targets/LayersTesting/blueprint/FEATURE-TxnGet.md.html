FEATURE: Transaction Get

FieldValue
Version20261027 V1
DescriptionImplements ledger txn get <id>, printing one stored transaction row.
Depends OnFEATURE-TxnPost.md, FEATURE-CliEntry.md, DATABASE.md
Providesledger txn get
Consumesledger_core.transactions, cli.registry

Purpose

ledger txn get <id> prints the header row txn_id,date,account,category,amount,memo and the stored transaction, formatted with txn_row from ledger_core.transactions, with the amount shown in two decimals.

Behavior

  • Exactly one argument is required; otherwise exit 2.
  • A non-integer id exits 3.
  • An absent id exits 4.
  • The command never writes to the database.

Database Interface

  • FEATURE-TXN-002 — read: get a transaction by id - supplies: txn_id - returns: txn_id, date, account, category, amount, memo

Programmatic Acceptance

=== AC txn-get-existing ===
Intent: A stored transaction prints with every column and the cents shown as a two-decimal amount.
Requires: executable=python3; scope=test

import csv import io from persistence.testing import db_session from cli.testing import cli_runner

acct, cat, tid = "ZZTG1", "ZZTGC1", 900001601 day, memo = "2026-04-05", "get probe" with db_session() as db: db.accounts.create(account=acct, name="Get Probe") db.categories.create(category=cat, description="Get Category") db.transactions.create(txn_id=tid, date=day, account=acct, category=cat, amount=1234, memo=memo) rc, out, err = cli_runner("txn", "get", str(tid)) print(out) print(err) assert rc == 0 rows = list(csv.reader(io.StringIO(out))) assert rows[0] == ["txn_id", "date", "account", "category", "amount", "memo"] assert rows[1] == [str(tid), day, acct, cat, "12.34", memo] === END AC txn-get-existing ===

Guardrails

  • The command is read-only and never writes to the database.
  • Amounts are displayed from integer cents with exactly two decimals; floating point is never used.
  • Failures write nothing to standard output.
