FEATURE: Account Rename

FieldValue
Version20261027 V1
DescriptionImplements ledger account rename <code> <name>, changing only an account's name and printing the updated row.
Depends OnFEATURE-AccountAdd.md, FEATURE-CliEntry.md, FEATURE-Validation.md, DATABASE.md
Providesledger account rename
Consumesledger_core.accounts, ledger_core.validation, cli.registry

Purpose

ledger account rename <code> <name> validates the new name, updates only the name column, and prints the header row and the updated account row account,name,transactions,balance.

Behavior

  • Exactly two arguments are required; otherwise exit 2.
  • Name validation (1 to 40 characters, no comma, no newline) happens first; a violation exits 3 and changes nothing.
  • An absent code exits 4 and changes nothing.
  • On success only name changes; the transaction count and balance in the output are computed live.

Database Interface

  • FEATURE-ACCOUNT-002 — read: check the account exists - supplies: account - returns: account, name
  • FEATURE-ACCOUNT-003 — write: rename an account - supplies: account, name - returns: account, name

Programmatic Acceptance

=== AC account-rename-success ===
Intent: Renaming prints the updated row and a separate read shows the new name persisted.
Requires: executable=python3; scope=test

import csv import io from persistence.testing import db_session from cli.testing import cli_runner

code, before, after = "ZZAR1", "Old Name", "New Name" with db_session() as db: db.accounts.create(account=code, name=before) rc, out, err = cli_runner("account", "rename", code, after) print(out) print(err) assert rc == 0 rows = list(csv.reader(io.StringIO(out))) assert rows[0] == ["account", "name", "transactions", "balance"] assert rows[1] == [code, after, str(0), "0.00"] back = db.accounts.get(account=code) assert back is not None name = back["name"] if isinstance(back, dict) else back.name assert name == after === END AC account-rename-success ===
