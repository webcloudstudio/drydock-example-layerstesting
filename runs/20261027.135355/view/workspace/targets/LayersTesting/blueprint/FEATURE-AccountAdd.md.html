FEATURE: Account Add

FieldValue
Version20261027 V1
DescriptionImplements ledger account add <code> <name> and the shared account_row helper.
Depends OnFEATURE-CliEntry.md, FEATURE-Validation.md, DATABASE.md
Providesledger account add, ledger_core.accounts
Consumesledger_core.validation, ledger_core.money, cli.registry

Purpose

Create one account and print its row. The module ledger_core.accounts also exports the helper the other account commands use to build an account row from live data.

Behavior

  1. ledger account add <code> <name> takes exactly two arguments; other counts exit 2.
  2. Validate the code (1 to 12 characters of A-Z0-9) and the name (1 to 40 characters, no comma or

newline). A violation exits 3.

  1. A code that is already stored exits 3 and leaves the stored account unchanged.
  2. Insert the account, then print CSV: the header account,name,transactions,balance and one row

with the new account, its name, 0 transactions, and balance 0.00.

  1. A failing command writes nothing to standard output.

Interface

ledger_core.accounts.account_row(db, code) returns None when the account is absent, otherwise the tuple (account, name, transactions, balance_cents) where transactions is the number of that account's stored transactions and balance_cents is the integer sum of their amounts. Both are computed from the database on every call. Formatting the balance as text is done by ledger_core.money.format_cents in the command, not in the helper.

Database Interface

  • FEATURE-ACCOUNT-002 — read: get an account by code - supplies: account - returns: account, name
  • FEATURE-ACCOUNT-001 — write: create an account - supplies: account, name - returns: account, name
  • FEATURE-TXN-005 — read: list an account's transactions to count and sum them - supplies: account - returns: amount

Intent: adding a new account exits 0, prints the header and one row with zero transactions and a zero balance, and the account reads back from the store.
Requires: executable=python3; scope=test

import csv import io from cli.testing import cli_runner from persistence.testing import db_session

acct = "ZZNA1" name = "Add Probe" with db_session() as db: code, out, err = cli_runner("account", "add", acct, name) print(out, err) assert code == 0 parsed = list(csv.reader(io.StringIO(out))) assert parsed[0] == ["account", "name", "transactions", "balance"] assert parsed[1] == [acct, name, "0", "0.00"] assert len(parsed) == 2 row = db.accounts.get(account=acct) assert row is not None got = row["name"] if isinstance(row, dict) else row.name assert got == name === END AC account-add-success ===
