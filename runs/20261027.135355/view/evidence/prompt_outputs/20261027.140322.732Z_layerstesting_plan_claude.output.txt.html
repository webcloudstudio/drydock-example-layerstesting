# FEATURE: Transaction Amend

| Field | Value |
|-------|-------|
| Version | 20261027 V1 |
| Description | Implements `ledger txn amend <id> <amount>`, which changes only a transaction's amount without leaving any account balance below zero. |
| Depends On | FEATURE-TxnPost.md, FEATURE-Validation.md, FEATURE-BalanceRule.md, FEATURE-CliEntry.md, DATABASE.md |
| Provides | ledger txn amend |
| Consumes | ledger_core.transactions, ledger_core.validation, ledger_core.balances, cli.registry |

## Questions

- None.

## Purpose

Amend the amount of an existing transaction. Only the amount changes; date, account, category, and memo are untouched. Persistence is reached only through `ledger_core.transactions`, which calls the generated `persistence` package.

## Behavior

1. Argument count other than two after `txn amend` exits 2.
2. The id must be an integer; otherwise exit 3.
3. The amount is validated with `ledger_core.validation` (`-?DIGITS[.D[D]]`, at most two decimals, never zero); a violation exits 3.
4. An absent id exits 4.
5. The resulting balance of the transaction's account is the stored balance minus the old amount plus the new amount, computed in integer cents through `ledger_core.balances`. A negative result exits 3 and nothing is written.
6. Otherwise only the amount is updated and the updated row is printed as `txn_id,date,account,category,amount,memo` with a two-decimal amount.
7. A failing command writes nothing to standard output and one diagnostic line to standard error.

## Database Interface

- None — persistence is owned by DATABASE.md and reached through `ledger_core.transactions`.

# FEATURE: Transfer

| Field | Value |
|-------|-------|
| Version | 20261027 V1 |
| Description | Implements `ledger transfer <from> <to> <amount> <date>`, an atomic two-row move of cash between distinct accounts in category TRANSFER. |
| Depends On | FEATURE-TxnPost.md, FEATURE-Validation.md, FEATURE-BalanceRule.md, FEATURE-CliEntry.md, DATABASE.md |
| Provides | ledger transfer |
| Consumes | ledger_core.transactions, ledger_core.validation, ledger_core.balances, cli.registry |

## Questions

- None.

## Purpose

Move cash between two accounts as two transaction rows that are stored together or not at all. Persistence is reached only through `ledger_core.transactions`, which calls the generated `persistence` package.

## Behavior

1. Argument count other than four after `transfer` exits 2.
2. Validate before any write: the amount is positive with at most two decimals, the date is a real `YYYY-MM-DD` date, both accounts exist, they differ, and category `TRANSFER` exists. Any violation exits 3.
3. The source balance after the debit must not be below zero, checked through `ledger_core.balances`; otherwise exit 3.
4. The outgoing row takes id max(txn_id)+1 (or 1 when empty): amount `-amount`, account `<from>`, category `TRANSFER`, memo `transfer to <to>`. The incoming row takes the next id: amount `+amount`, account `<to>`, memo `transfer from <from>`.
5. Both rows are inserted atomically and printed under the header `txn_id,date,account,category,amount,memo`.
6. A failing command writes nothing to standard output and stores neither row.

## Database Interface

- None — persistence is owned by DATABASE.md and reached through `ledger_core.transactions`.

## Programmatic Acceptance

# FEATURE: Report Balances

| Field | Value |
|-------|-------|
| Version | 20261027 V1 |
| Description | Implements `ledger report balances`, a per-account count and balance report with a total row, computed from stored data. |
| Depends On | FEATURE-CliEntry.md, FEATURE-Validation.md, DATABASE.md |
| Provides | ledger report balances |
| Consumes | ledger_core.money, cli.registry |

## Questions

- None.

## Purpose

Report each account's transaction count and balance. Every value is computed from queries over stored rows; none is embedded. Persistence is reached only through the generated `persistence` package via `ledger_core`.

## Behavior

1. Header `account,name,transactions,balance`.
2. One row per account ordered by account code; accounts without transactions appear with count 0 and balance `0.00`.
3. A final row `TOTAL,,<count>,<sum>` where count is the number of all transactions and sum is the sum of all amounts.
4. Balances are integer-cent sums formatted with exactly two decimals, a leading `-` when negative, and no thousands separator.
5. Extra arguments exit 2. Output uses `\n` endings, no quoting, and no trailing spaces.

## Database Interface

- None — persistence is owned by DATABASE.md and reached through `ledger_core`.

## Programmatic Acceptance

=== AC report-balances-values ===
Intent: Each account row carries the count and formatted balance derived from stored transactions, and the TOTAL row carries the overall count and sum; expectations are computed from the stored rows.

from cli.testing import cli_runner
from persistence.testing import db_session
import csv
import io

def f(row, name):
    return row[name] if isinstance(row, dict) else getattr(row, name)

def fmt(c):
    sign = "-" if c < 0 else ""
    q, r = divmod(abs(c), 100)
    return f"{sign}{q}.{r:02d}"

a1, a2, cat = "ZZRB1", "ZZRB2", "ZZRBC1"
with db_session() as db:
    db.accounts.create(account=a1, name="Report One")
    db.accounts.create(account=a2, name="Report Two")
    db.categories.create(category=cat, description="Report Category")
    db.transactions.create(txn_id=900400001, date="2026-05-01", account=a1, category=cat, amount=123456, memo="")
    db.transactions.create(txn_id=900400002, date="2026-05-02", account=a1, category=cat, amount=-2345, memo="")
    db.transactions.create(txn_id=900400003, date="2026-05-03", account=a2, category=cat, amount=5, memo="")

    print(out)
    print(err)

    rows = list(csv.reader(io.StringIO(out)))
    assert rows[0] == ["account", "name", "transactions", "balance"]
    txns = db.transactions.list()
    expected = []
    for acc in sorted(db.accounts.list(), key=lambda r: f(r, "account")):
        mine = [f(t, "amount") for t in txns if f(t, "account") == f(acc, "account")]
        expected.append([f(acc, "account"), f(acc, "name"), str(len(mine)), fmt(sum(mine))])
    expected.append(["TOTAL", "", str(len(txns)), fmt(sum(f(t, "amount") for t in txns))])

# FEATURE: Report Categories

| Field | Value |
|-------|-------|
| Version | 20261027 V1 |
| Description | Implements `ledger report categories`, per-category transaction count, inflow, outflow, and net with a total row, computed from stored data. |
| Depends On | FEATURE-CliEntry.md, FEATURE-Validation.md, DATABASE.md |
| Provides | ledger report categories |
| Consumes | ledger_core.money, cli.registry |

## Questions

- None.

## Purpose

Report totals by category, including categories with no transactions. Every value is computed from queries over stored rows. Persistence is reached only through the generated `persistence` package via `ledger_core`.

## Behavior

1. Header `category,description,transactions,inflow,outflow,net`.
2. One row per category ordered by category code, including categories with no transactions (count 0 and zero amounts).
3. `inflow` is the sum of positive amounts, `outflow` the sum of the absolute values of negative amounts written as a positive number, and `net` is inflow minus outflow.
4. A final row `TOTAL,,<count>,<inflow>,<outflow>,<net>` over all transactions.
5. Amounts use exactly two decimals, a leading `-` when negative, and no thousands separator.
6. Extra arguments exit 2. Output uses `\n` endings, no quoting, and no trailing spaces.

## Database Interface

- None — persistence is owned by DATABASE.md and reached through `ledger_core`.

## Programmatic Acceptance

=== AC report-categories-values ===
Intent: Each category row and the TOTAL row match inflow, outflow, net, and count derived from stored transactions, including a category with mixed signs and an empty category.

from cli.testing import cli_runner
from persistence.testing import db_session
import csv
import io

def f(row, name):
    return row[name] if isinstance(row, dict) else getattr(row, name)

def fmt(c):
    sign = "-" if c < 0 else ""
    q, r = divmod(abs(c), 100)
    return f"{sign}{q}.{r:02d}"

def summarize(amounts):
    inflow = sum(a for a in amounts if a > 0)
    outflow = sum(-a for a in amounts if a < 0)
    return [str(len(amounts)), fmt(inflow), fmt(outflow), fmt(inflow - outflow)]

acct, mixed, empty = "ZZRC1", "ZZRCM", "ZZRCE"
with db_session() as db:
    db.accounts.create(account=acct, name="Category Account")
    db.categories.create(category=mixed, description="Mixed Category")
    db.categories.create(category=empty, description="Empty Category")
    db.transactions.create(txn_id=900500001, date="2026-05-01", account=acct, category=mixed, amount=100050, memo="")
    db.transactions.create(txn_id=900500002, date="2026-05-02", account=acct, category=mixed, amount=-2505, memo="")
    db.transactions.create(txn_id=900500003, date="2026-05-03", account=acct, category=mixed, amount=-7, memo="")
    code, out, err = cli_runner("report", "categories")
    print(out)
    print(err)
    assert code == 0
    rows = list(csv.reader(io.StringIO(out)))
    assert rows[0] == ["category", "description", "transactions", "inflow", "outflow", "net"]
    txns = db.transactions.list()
    expected = []
    for cat in sorted(db.categories.list(), key=lambda r: f(r, "category")):
        amounts = [f(t, "amount") for t in txns if f(t, "category") == f(cat, "category")]
        expected.append([f(cat, "category"), f(cat, "description")] + summarize(amounts))
    expected.append(["TOTAL", ""] + summarize([f(t, "amount") for t in txns]))
    assert rows[1:] == expected
