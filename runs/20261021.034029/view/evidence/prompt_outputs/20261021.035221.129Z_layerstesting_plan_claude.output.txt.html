| Field | Type | Notes |
|---|---|---|
| `category` | VARCHAR(12) PK NOT NULL | Category code, `A-Z` and `0-9`. |

## Guardrails

- Amounts are stored as integer cents and never as floating point.
- Application code reaches the store only through the generated persistence package.
- Within a release the schema is built once and never migrated.
