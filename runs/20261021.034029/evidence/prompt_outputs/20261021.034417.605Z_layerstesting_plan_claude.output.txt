# FEATURE: Report Balances

| Field       | Value |
|-------------|-------|
| Version     | 20261021 V1 |
| Description | The `ledger report balances` command writes each account's transaction count and balance, then a TOTAL row, all computed from the database. |
| Depends On  | DATABASE.md, FEATURE-Load-Accounts.md, FEATURE-Load-Transactions.md |
| Provides    | ledger report balances |
| Consumes    | accounts.list, transactions.list |

## Questions

- None.

## Purpose

`ledger report balances` reads the accounts and transactions tables and writes one CSV row per account, ordered by account code, followed by a TOTAL row.

## Behavior

- Header row: `account,name,transactions,balance`.
- One row per account: `account,name,transactions,balance`. `transactions` is the count of that account's transactions. `balance` is the sum of their amounts.
- Amounts are written with exactly two decimal places, a leading `-` when negative, and no thousands separator.
- TOTAL row: `TOTAL,,<count>,<sum>`, where the count and sum cover all transactions.
- Every value comes from a query. No report answer is embedded in application code.
- Exit `0` on success. Exit `1` when the database is unreachable or the tables are missing.

## Database Interface

- `FEATURE-LEDGER-003` — read: list accounts for the report - returns: `account`, `name`
- `FEATURE-LEDGER-011` — read: list transactions to total each account - returns: `account`, `amount`

## Programmatic Acceptance

# FEATURE: Report Categories

| Field       | Value |
|-------------|-------|
| Version     | 20261021 V1 |
| Description | The `ledger report categories` command writes inflow, outflow, and net per category, including categories with no transactions, then a TOTAL row, all computed from the database. |
| Depends On  | DATABASE.md, FEATURE-Load-Categories.md, FEATURE-Load-Transactions.md |
| Provides    | ledger report categories |
| Consumes    | categories.list, transactions.list |

## Questions

- None.

## Purpose

`ledger report categories` reads the categories and transactions tables and writes one CSV row per category, ordered by category code, followed by a TOTAL row.

## Behavior

- Header row: `category,description,transactions,inflow,outflow,net`.
- One row per category, including categories with no transactions, which show zero counts and zero amounts.
- `inflow` is the sum of positive amounts. `outflow` is the sum of the absolute values of negative amounts, written as a positive number. `net` is `inflow - outflow`.
- TOTAL row: `TOTAL,,<count>,<inflow>,<outflow>,<net>`.
- Amount formatting follows the same two-decimal rule as the balances report.
- Exit `0` on success. Exit `1` when the database is unreachable or the tables are missing.

## Database Interface

- `FEATURE-LEDGER-008` — read: list categories for the report - returns: `category`, `description`
- `FEATURE-LEDGER-011` — read: list transactions to total each category - returns: `category`, `amount`

## Programmatic Acceptance

# FEATURE: Report Unknown

| Field       | Value |
|-------------|-------|
| Version     | 20261021 V1 |
| Description | An unknown or missing report name exits 2 with a diagnostic on standard error and writes nothing to standard output. |
| Depends On  | FEATURE-Cli-Usage.md |
| Provides    | ledger report (report name validation) |

## Questions

- None.

## Purpose

`ledger report <name>` accepts only the names `balances`, `categories`, and `monthly`. Any other name, or a missing name, is a usage error.

## Behavior

- An unknown report name exits `2`.

# FEATURE: Account Add

| Field       | Value |
|-------------|-------|
| Version     | 20261021 V1 |
| Description | The `ledger account add` command validates an account code and name, rejects duplicates, and writes the new account row. |
| Depends On  | DATABASE.md, FEATURE-Schema-Init.md |
| Provides    | ledger account add |
| Consumes    | accounts.create, accounts.get |

## Questions

- None.

## Purpose

`ledger account add <code> <name>` creates one account with no transactions and writes its row to standard output.

## Behavior

- Code: 1 to 12 characters from `A-Z` and `0-9`. Otherwise exit `3`.
- Name: 1 to 40 characters, with no comma or newline. Otherwise exit `3`.
- An existing code exits `3`.
- All validation and the duplicate check run before the first write, so a rejected add writes nothing.
- On success, standard output is the header `account,name,transactions,balance` followed by the new row with `transactions` `0` and `balance` `0.00`.
- Exit `0` on success. Exit `1` when the database is unreachable or the tables are missing.

## Database Interface

- `FEATURE-LEDGER-001` — write: insert the new account - supplies: `account`, `name` - returns: `account`, `name`
- `FEATURE-LEDGER-002` — read: look up an account by code to detect a duplicate - supplies: `account` - returns: `account`, `name`

## Programmatic Acceptance
