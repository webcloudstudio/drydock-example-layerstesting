  transactions(txn_id INTEGER PK, date TEXT NOT NULL, account TEXT NOT NULL REFERENCES accounts,

  stored aggregates.

instructions: |
  Create `ledger` at the application root: an executable POSIX sh launcher that uses .venv/bin/python
  when present (else python3) to call cli.main(sys.argv[1:]) and exit with its return value.
  cli/__init__.py defines main(argv) -> int and cli/testing.py defines cli_runner per the CLI
  foundation contract. cli/errors.py defines CliError with exit_code and subclasses
  OperationalError (1), UsageError (2), RejectedError (3), NotFoundError (4).
  Dispatch: argv[0] names a module `cli.commands.<command>` imported lazily; each module exposes
  `run(args: list[str]) -> list[str]` returning output lines (no printing). main buffers output and
  writes it to stdout only when run succeeds; on CliError it writes one diagnostic line to stderr,
  nothing to stdout, and returns the error's exit_code; any other exception is exit 1. A missing
  command module is a UsageError. No command logic lives here.
