## Planning Instructions

### Delivery Shape

The system is a single-process command-line ledger. The `ledger` executable at the application root reads command arguments, the database location from `DATABASE_URL` or `DATABASE_PATH`, and CSV files for loads. It writes CSV to standard output, diagnostics to standard error, and exits with codes 0 to 4.

Each command resolves the database, validates every input, checks every balance rule against stored data, and then either performs all of its writes in one database transaction or performs none. Reports read stored data only.

Repository-call contracts for `DATABASE.md`, all with consumer sensitivity `data` (CLI consumer):

| Contract | Operation | Input | Output |
|---|---|---|---|
| FEATURE-LEDGER-001 | Initialize schema and clear rows | none | row counts per table |
| FEATURE-LEDGER-002 | Count rows per table | none | table and count pairs |
| FEATURE-LEDGER-003 | Load one table atomically | table name and row DTOs | loaded count |
| FEATURE-LEDGER-004 | Account add, get, rename, delete | AccountDTO | AccountView with transaction count and balance |
| FEATURE-LEDGER-005 | Transaction post, get, amend, delete | TransactionDTO | TransactionRow |
| FEATURE-LEDGER-006 | Transfer | TransferDTO | two TransactionRow values |
| FEATURE-LEDGER-007 | Reports | report name | ReportRow sequence |

Amounts cross these contracts as integer cents.
