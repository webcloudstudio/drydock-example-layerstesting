FEATURE: Report Categories

FieldValue
Version20261027 V1
DescriptionReport transaction count, inflow, outflow and net per category, including unused categories.
Depends OnFEATURE-ReportBalances.md
Providesledger report categories
Consumesledger report balances

Purpose

ledger report categories summarizes stored transactions per category and in total.

Trigger

Command line: ./ledger report categories, added to the report-name table in cli/commands/report.py. Extra arguments are a UsageError (exit 2).

Output

Header category,description,transactions,inflow,outflow,net, one row per stored category ordered by code (categories with no transactions included with count 0 and zero amounts), then TOTAL,,<count>,<inflow>,<outflow>,<net>. inflow is the sum of positive amounts, outflow the sum of absolute values of negative amounts written as a positive number, and net is inflow - outflow. All money uses exactly two decimals computed from integer cents.

Database Interface

  • None — persistence is owned by DATABASE.md.

=== AC categories-computed-from-storage ===
Intent: Adding one inflow transaction raises that category's count and inflow and the TOTAL inflow by exactly that amount.

import csv import io from decimal import Decimal from persistence.testing import db_session from cli.testing import cli_runner

cat = "ZZRCSTO" delta = 3333 with db_session() as db: db.accounts.create(account="ZZRCS1", name="Rpt Cat Store") db.categories.create(category=cat, description="Rpt Cat Store")

def snapshot(): code, out, err = cli_runner("report", "categories") print(out, err) assert code == 0 rows = list(csv.reader(io.StringIO(out))) mine = [r for r in rows[1:-1] if r[0] == cat][0] return int(mine[2]), Decimal(mine[3]), Decimal(rows[-1][3])

count_before, inflow_before, total_before = snapshot() new_id = max([r.txn_id for r in db.transactions.list()], default=0) + 1 db.transactions.create(txn_id=new_id, date="2099-03-11", account="ZZRCS1", category=cat, amount=delta, memo="rcs") count_after, inflow_after, total_after = snapshot() assert count_after == count_before + 1 assert inflow_after - inflow_before == Decimal(delta) / 100 assert total_after - total_before == Decimal(delta) / 100 === END AC categories-computed-from-storage ===
