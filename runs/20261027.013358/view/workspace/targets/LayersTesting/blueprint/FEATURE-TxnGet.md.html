FEATURE: Transaction Get

FieldValue
Version20261027 V1
DescriptionImplements ledger txn get <id> printing one stored transaction row.
Depends OnFEATURE-TxnPost.md, DATABASE.md
Providesledger txn get
Consumesledger txn post

Purpose

Read one transaction by id through the txn verb table in cli/commands/txn.py.

Behavior

  1. Usage: ledger txn get <id>; any other argument count is a usage error (exit 2).
  2. An id that is not a string of decimal digits is rejected with exit 3.
  3. An absent id exits 4 with nothing on standard output.
  4. Otherwise print the header txn_id,date,account,category,amount,memo and the stored row, amount with two decimals.

Database Interface

  • None — persistence is owned by DATABASE.md.

Programmatic Acceptance

=== AC txn-get-success ===
Intent: Get prints the header and the stored row, with the amount rendered from integer cents.

import csv import io from cli.testing import cli_runner from persistence.testing import db_session

acct = "ZZTGET1" cat = "ZZTGCAT1" date = "2026-04-10" memo = "get me" amount_cents = 1250 amount_text = "12.50" with db_session() as db: db.accounts.create(account=acct, name="Get One") db.categories.create(category=cat, description="Get Cat") txn_id = max([r.txn_id for r in db.transactions.list()], default=0) + 1 db.transactions.create( txn_id=txn_id, date=date, account=acct, category=cat, amount=amount_cents, memo=memo ) exit_code, out, err = cli_runner("txn", "get", str(txn_id)) print(out) print(err) assert exit_code == 0 rows = list(csv.reader(io.StringIO(out))) assert rows[0] == ["txn_id", "date", "account", "category", "amount", "memo"] assert rows[1] == [str(txn_id), date, acct, cat, amount_text, memo] assert len(rows) == 2 === END AC txn-get-success ===
