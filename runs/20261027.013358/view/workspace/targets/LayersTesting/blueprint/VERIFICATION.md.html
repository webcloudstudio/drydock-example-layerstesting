Purpose

This is the terminal story. Every command story has closed before it runs. It proves the assembled ledger passes all 43 supplied checks in sources/run.sh and that the application's own suite passes through bin/test.sh. Application code never reads sources/run.sh or any seed file.

Assembly and Intent

  • Run sh sources/run.sh from the application root, unfiltered; exit status is the verdict.
  • The grader chooses its own temporary database when DATABASE_URL is unset, so the child process

is run without DATABASE_URL and DATABASE_PATH; this protects the configured store from init.

  • Run sh bin/test.sh and require exit zero.
  • Do not modify, regenerate, or substitute any file under sources/.

Database Interface

  • None — persistence is owned by DATABASE.md.

Programmatic Acceptance

=== AC verify-grader-full ===
Intent: The supplied grader sh sources/run.sh passes every check, so the runner exits zero.
Suite: full
Requires: executable=sh; scope=test

import os import subprocess import sys

env = {k: v for k, v in os.environ.items() if k not in ("DATABASE_URL", "DATABASE_PATH")} result = subprocess.run( ["sh", "sources/run.sh"], capture_output=True, text=True, env=env, ) print(result.stdout) print(result.stderr, file=sys.stderr) assert result.returncode == 0 === END AC verify-grader-full ===
