## Persistence Boundary

| Boundary | Rule |
|----------|------|
| Raw storage access | Only the generated `persistence/` package reaches the store. |
| Caller dependency | Features depend on declared access patterns and their DTOs, not on schemas. |
| Implementation | Generated from this file at the DATABASE build step; never written by hand. |
| Money | Amounts are integer cents. No floating point at any layer. |
| Reports | Balances and report totals are computed by callers from list rows, never stored. |

## Schemas

## `accounts`

| Field | Type | Notes |
|-------|------|-------|
| account | TEXT PK | Account code, 1 to 12 characters of A-Z and 0-9. |
| name | TEXT NOT NULL | 1 to 40 characters, no comma or newline. |

## `categories`

| Field | Type | Notes |
|-------|------|-------|
| category | TEXT PK | Category code, 1 to 12 characters of A-Z and 0-9. |
| description | TEXT NOT NULL | 1 to 40 characters, no comma or newline. |

## `transactions`

| Field | Type | Notes |
|-------|------|-------|
| txn_id | INTEGER PK | Kept from a load file, or one more than the largest present. |
| date | TEXT NOT NULL | Calendar date written YYYY-MM-DD. |
| account | TEXT NOT NULL REFERENCES accounts(account) | Owning account. |
| category | TEXT NOT NULL REFERENCES categories(category) | Category. |
| amount | INTEGER NOT NULL | Integer cents, never zero. |
| memo | TEXT NOT NULL | 0 to 60 characters, no comma or newline. |

- INDEX (account, date)
- INDEX (date, account)

    )
    db.transactions.create(
        txn_id=id_other, date="2026-05-03", account=acct_b, category=cat, amount=200, memo="o"
