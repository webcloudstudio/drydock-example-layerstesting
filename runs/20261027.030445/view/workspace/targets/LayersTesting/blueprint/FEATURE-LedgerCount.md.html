FEATURE: Ledger Count

FieldValue
Version20261027 V1
DescriptionThe ledger count command reports the number of rows in each table.
Depends OnARCHITECTURE.md, DATABASE.md, FEATURE-LedgerCli.md
Providesledger count
Consumesledger

Purpose

ledger count shows how many accounts, categories, and transactions are stored.

Behavior

  • Takes no arguments; any argument is a usage error (exit 2).
  • Writes the header table,rows, then the rows accounts, categories, transactions in that order, each with its stored row count. Counts come from the list operations of the database, never from embedded numbers.
  • Exits 0. When the database cannot be opened it exits 1 with empty standard output and changes nothing.
  • The handler is registered as ("count",) and returns the CSV rows.

Database Interface

  • None — persistence is owned by DATABASE.md.

Programmatic Acceptance

=== AC count-follows-new-rows ===
Intent: The account count rises by exactly the number of accounts created, read back through a second count invocation.

import csv import io

from persistence.testing import db_session from cli.testing import cli_runner

def accounts_count(): code, out, err = cli_runner("count") assert code == 0 rows = list(csv.reader(io.StringIO(out))) return int(dict((r[0], r[1]) for r in rows[1:])["accounts"])

with db_session() as db: before = accounts_count() codes = ["ZQN2", "ZQN3", "ZQN4"] for code_value in codes: db.accounts.create(account=code_value, name="More " + code_value) after = accounts_count() assert after == before + len(codes) === END AC count-follows-new-rows ===
