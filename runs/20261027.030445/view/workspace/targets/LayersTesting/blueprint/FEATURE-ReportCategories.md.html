FEATURE: Report Categories

FieldValue
Version20261027 V1
DescriptionImplements ledger report categories, per-category transaction counts with inflow, outflow, and net computed from stored transactions.
Depends OnFEATURE-ReportBalances.md, FEATURE-LedgerCli.md, DATABASE.md
Providesledger report categories
Consumesledger, categories, transactions

Purpose

Show how cash moved by category, including categories that have no transactions.

Interface

ledger report categories

Standard output on success (exit 0):

  • header category,description,transactions,inflow,outflow,net
  • one row per category ordered by code ascending, including categories with no transactions
  • final row TOTAL,,<count>,<inflow>,<outflow>,<net>

Behavior

  1. Read categories with db.categories.list and transactions with db.transactions.list.
  2. inflow is the sum of positive amounts; outflow is the sum of the absolute values of negative amounts, written as a positive number; net is inflow - outflow.
  3. All amounts are integer cents, written with exactly two decimals and no thousands separator.
  4. The TOTAL count is the number of transactions; its inflow, outflow, and net are the column sums.
  5. With no categories the output is the header and TOTAL,,0,0.00,0.00,0.00.
  6. The command is read-only.

Database Interface

  • None — persistence is owned by DATABASE.md.

=== AC report-categories-no-categories ===
Intent: With no categories the report writes only its header and a zero TOTAL row.

import csv import io from cli.testing import cli_runner from persistence.testing import db_session

with db_session() as db: db.transactions.delete_all(min_txn_id=0) db.categories.delete_all(min_category="") db.accounts.delete_all(min_account="") code, out, err = cli_runner("report", "categories") print(out) print(err) assert code == 0 rows = list(csv.reader(io.StringIO(out))) assert rows == [ ["category", "description", "transactions", "inflow", "outflow", "net"], ["TOTAL", "", "0", "0.00", "0.00", "0.00"], ] === END AC report-categories-no-categories ===

=== AC report-categories-net-negative ===
Intent: A category with only withdrawals reports zero inflow, a positive outflow, and a negative net with a leading minus sign and two decimals.

import csv import io import re from decimal import Decimal from cli.testing import cli_runner from persistence.testing import db_session

acct = "ZQG5" cat = "ZQG5" spent = 1275 with db_session() as db: db.accounts.create(account=acct, name="Spend Account") db.categories.create(category=cat, description="Spend Category") base = max([r.txn_id for r in db.transactions.list()] or [0]) + 1 db.transactions.create(txn_id=base, date="2026-06-01", account=acct, category=cat, amount=-spent, memo="") code, out, err = cli_runner("report", "categories") print(out) print(err) assert code == 0 by_code = {r[0]: r for r in csv.reader(io.StringIO(out))} row = by_code[cat] assert Decimal(row[3]) == 0 assert Decimal(row[4]) == Decimal(spent).scaleb(-2) assert Decimal(row[5]) == -Decimal(spent).scaleb(-2) assert re.fullmatch(r"-\d+\.\d{2}", row[5]) assert not row[4].startswith("-") === END AC report-categories-net-negative ===
