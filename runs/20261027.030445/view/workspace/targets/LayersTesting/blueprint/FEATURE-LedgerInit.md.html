FEATURE: Ledger Init

FieldValue
Version20261027 V1
DescriptionThe ledger init command resets the ledger to empty.
Depends OnARCHITECTURE.md, DATABASE.md, FEATURE-LedgerCli.md
Providesledger init
Consumesledger

Purpose

ledger init prepares an empty ledger for loading and use and removes existing ledger records when rerun.

Behavior

  • Takes no arguments; any argument is a usage error (exit 2).
  • Removes every transaction first, then every category and every account, in one persistence-library transaction, so foreign keys hold and the unit is atomic.
  • Writes nothing to standard output and exits 0. Rerunning it removes all records again.
  • Applies no DDL. If the database cannot be opened it exits 1 and changes nothing.
  • The handler returns None and is registered as ("init",).

Database Interface

  • None — persistence is owned by DATABASE.md.

Programmatic Acceptance

=== AC init-empties-all-tables ===
Intent: After init succeeds with empty standard output, accounts, categories, and transactions read back as empty even though rows existed before.

from persistence.testing import db_session from cli.testing import cli_runner

with db_session() as db: db.accounts.create(account="ZQI1", name="Init Account") db.categories.create(category="ZQI1", description="Init Category") db.transactions.create( txn_id=920001, date="2026-06-01", account="ZQI1", category="ZQI1", amount=1000, memo="" ) assert db.transactions.get(txn_id=920001) is not None code, out, err = cli_runner("init") print(out) print(err) assert code == 0 assert out == "" assert db.transactions.list() == [] assert db.categories.list() == [] assert db.accounts.list() == [] === END AC init-empties-all-tables ===

Intent: When the database cannot be opened, init exits 1 with empty standard output.

import os import shutil import tempfile
