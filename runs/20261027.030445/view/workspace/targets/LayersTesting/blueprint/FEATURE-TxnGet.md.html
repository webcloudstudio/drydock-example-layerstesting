FEATURE: Transaction Get

FieldValue
Version20261027 V1
DescriptionImplements ledger txn get, which writes one stored transaction row by id.
Depends OnFEATURE-TxnPost.md, FEATURE-LedgerCli.md, DATABASE.md
Providesledger txn get
Consumesledger, transactions

Purpose

Let the shop look up a single recorded transaction by its id.

Trigger

ledger txn get <id> invoked from the command line.

Sequence

  1. Require exactly one argument after get; otherwise raise the shared usage error (exit 2).
  2. Parse the id as an integer; a non-integer id exits 3.
  3. Read the transaction. An absent id exits 4.
  4. Write the header txn_id,date,account,category,amount,memo and the stored row, with the amount at exactly two decimals.

Database Interface

  • FEATURE-TXN-002 — read: get the transaction by id - supplies: txn_id - returns: txn_id, date, account, category, amount, memo

Behavior Rules

  • The command never writes to the database.
  • A failing command writes nothing to standard output and one diagnostic line to standard error.

Programmatic Acceptance

=== AC txn-get-success ===
Intent: Getting an existing transaction exits 0 and writes its stored values with the amount formatted from the stored cents.

import csv import io from decimal import Decimal from persistence.testing import db_session from cli.testing import cli_runner

acct = "ZTG1" cat = "ZTG1" txn_id = 940001 date = "2026-04-01" cents = 4550 memo = "walk in sale" with db_session() as db: db.accounts.create(account=acct, name="Get Account") db.categories.create(category=cat, description="Get Category") db.transactions.create( txn_id=txn_id, date=date, account=acct, category=cat, amount=cents, memo=memo ) exit_code, out, err = cli_runner("txn", "get", str(txn_id)) print(exit_code, out, err) assert exit_code == 0 rows = list(csv.reader(io.StringIO(out))) assert rows[0] == ["txn_id", "date", "account", "category", "amount", "memo"] amount_text = f"{Decimal(cents) / 100:.2f}" assert rows[1] == [str(txn_id), date, acct, cat, amount_text, memo] === END AC txn-get-success ===

=== AC txn-get-absent ===
Intent: Getting an id that is not stored exits 4 with nothing on standard output.

from persistence.testing import db_session from cli.testing import cli_runner

with db_session() as db: stored = [r.txn_id for r in db.transactions.list()] absent = (max(stored) + 1000) if stored else 999 exit_code, out, err = cli_runner("txn", "get", str(absent)) print(exit_code, out, err) assert exit_code == 4 assert out == "" === END AC txn-get-absent ===

=== AC txn-get-after-post ===
Intent: A transaction posted through the CLI is returned unchanged by a later get, proving the post persisted.

import csv import io from persistence.testing import db_session from cli.testing import cli_runner

acct = "ZTG3" cat = "ZTG3" amount_text = "20.25" date = "2026-04-05" memo = "round trip" with db_session() as db: db.accounts.create(account=acct, name="Round Trip") db.categories.create(category=cat, description="Round Trip") exit_code, out, err = cli_runner("txn", "post", acct, cat, amount_text, date, memo) print(exit_code, out, err) assert exit_code == 0 posted = list(csv.reader(io.StringIO(out)))[1] exit_code, out, err = cli_runner("txn", "get", posted[0]) print(exit_code, out, err) assert exit_code == 0 fetched = list(csv.reader(io.StringIO(out)))[1] assert fetched == posted === END AC txn-get-after-post ===
