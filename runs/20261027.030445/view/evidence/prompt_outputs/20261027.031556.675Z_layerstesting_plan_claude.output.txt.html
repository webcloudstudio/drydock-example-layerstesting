# FEATURE: Transaction Delete

| Field | Value |
|-------|-------|
| Version | 20261027 V1 |
| Description | Implements `ledger txn delete <id>`, which removes one transaction unless the removal would leave an account balance below zero. |
| Depends On | FEATURE-TxnPost.md, FEATURE-LedgerCli.md, DATABASE.md |
| Provides | ledger txn delete |
| Consumes | ledger, transactions |

## Questions

- None.

## Purpose

Remove a single stored transaction by id. The command validates everything before it writes, and a rejected command changes nothing.

## Interface

`ledger txn delete <id>`

| Outcome | Exit | Standard output |
|---------|------|-----------------|
| Deleted | 0 | CSV rows `deleted` and the id |
| Id not stored | 4 | nothing |
| Id not an integer | 3 | nothing |
| Removal would leave the owning account balance below zero | 3 | nothing |

## Behavior

1. Parse the id as an integer. A value that is not an integer is rejected with exit 3 before any lookup.
2. Look the transaction up through `db.transactions.get`. An absent id exits 4 (not-found is checked before the balance rule).
3. Compute the owning account's balance after removal, in integer cents, from `db.transactions.list(account=...)`. If it is below zero, exit 3 and write nothing.
4. Remove the row with `db.transactions.delete`, then write `deleted` and the id as CSV (`\n` line endings, no quoting).
5. Diagnostics go to standard error only.

## Database Interface

- None — persistence is owned by DATABASE.md.

## Programmatic Acceptance

# FEATURE: Transfer

| Field | Value |
|-------|-------|
| Version | 20261027 V1 |
| Description | Implements `ledger transfer`, which records an equal debit and credit in category TRANSFER as one all-or-nothing change. |
| Depends On | FEATURE-TxnPost.md, FEATURE-LedgerCli.md, DATABASE.md |
| Provides | ledger transfer |
| Consumes | ledger, accounts, categories, transactions |

## Questions

- None.

## Purpose

Move cash between two distinct accounts. Both transaction rows are stored or neither is, and total cash held never changes.

## Interface

`ledger transfer <from> <to> <amount> <date>`

| Outcome | Exit | Standard output |
|---------|------|-----------------|
| Transferred | 0 | header `txn_id,date,account,category,amount,memo`, then the outgoing row, then the incoming row |
| Any rule violated | 3 | nothing |

## Behavior

1. Validate before any write: both accounts exist (an unknown account is exit 3), the accounts differ, the amount matches `DIGITS[.D[D]]` and is strictly positive, the date is a real Gregorian calendar date, category `TRANSFER` exists (otherwise exit 3, it is not created implicitly), and the source balance after the debit is not below zero.
2. Let `n` be one more than the largest stored `txn_id`, or 1 when empty. Store the outgoing row with id `n`: account `<from>`, category `TRANSFER`, amount `-amount`, memo naming `<to>` as `transfer to <to>`.
3. Store the incoming row with id `n+1`: account `<to>`, category `TRANSFER`, amount `+amount`, memo `transfer from <from>`.
4. Both writes happen in one persistence-library transaction so a failure leaves neither row.
5. Write the header and the two rows with amounts at exactly two decimals.

## Database Interface

- None — persistence is owned by DATABASE.md.

## Programmatic Acceptance

=== AC transfer-success-two-rows ===

import csv
import io
import re
from decimal import Decimal
from cli.testing import cli_runner
from persistence.testing import db_session

src = "ZQF1"
dst = "ZQF2"
fund_cat = "ZQFC"
amount_text = "100.00"
date = "2026-06-10"
cents = int(Decimal(amount_text) * 100)
funding = 50000
with db_session() as db:
    db.accounts.create(account=src, name="Source")
    db.accounts.create(account=dst, name="Dest")
    db.categories.create(category=fund_cat, description="Funding")
    if db.categories.get(category="TRANSFER") is None:
        db.categories.create(category="TRANSFER", description="Internal transfer")
    base = max([r.txn_id for r in db.transactions.list()] or [0]) + 1
    db.transactions.create(txn_id=base, date="2026-06-01", account=src, category=fund_cat, amount=funding, memo="")
    nxt = base + 1
    code, out, err = cli_runner("transfer", src, dst, amount_text, date)
    print(out)
    print(err)
    assert code == 0
    rows = list(csv.reader(io.StringIO(out)))
    assert rows[0] == ["txn_id", "date", "account", "category", "amount", "memo"]
    assert len(rows) == 3
    out_row, in_row = rows[1], rows[2]
    assert int(out_row[0]) == nxt
    assert int(in_row[0]) == nxt + 1
    assert out_row[1] == date and in_row[1] == date
    assert out_row[2] == src and in_row[2] == dst
    assert out_row[3] == "TRANSFER" and in_row[3] == "TRANSFER"
    assert Decimal(out_row[4]) == -Decimal(amount_text)
    assert Decimal(in_row[4]) == Decimal(amount_text)
    assert re.fullmatch(r"-?\d+\.\d{2}", out_row[4])
    assert re.fullmatch(r"-?\d+\.\d{2}", in_row[4])
    assert dst in out_row[5]
    assert src in in_row[5]
    stored_out = db.transactions.get(txn_id=nxt)
    stored_in = db.transactions.get(txn_id=nxt + 1)
    assert stored_out is not None and stored_in is not None
    assert stored_out.amount == -cents and stored_in.amount == cents
    assert stored_out.memo == out_row[5] and stored_in.memo == in_row[5]
    src_bal = sum(t.amount for t in db.transactions.list(account=src))
    dst_bal = sum(t.amount for t in db.transactions.list(account=dst))
    assert src_bal == funding - cents
    assert dst_bal == cents
    assert src_bal + dst_bal == funding

# FEATURE: Report Balances

| Field | Value |
|-------|-------|
| Version | 20261027 V1 |
| Description | Implements `ledger report balances`, one row per account with its transaction count and balance computed from stored transactions. |
| Depends On | FEATURE-LoadTransactions.md, FEATURE-LedgerCli.md, DATABASE.md |
| Provides | ledger report balances |
| Consumes | ledger, accounts, transactions |

## Questions

- None.

## Purpose

Report the cash held in each account. Every value is computed from stored rows at the time of the command; nothing is embedded.

## Interface

`ledger report balances`

Standard output on success (exit 0), CSV with `\n` endings and no quoting:

- header `account,name,transactions,balance`
- one row per account ordered by code ascending
- final row `TOTAL,,<count>,<sum>`, where `<count>` is the total number of transactions and `<sum>` the sum of all balances

## Behavior

1. Read accounts with `db.accounts.list` and each account's transactions with `db.transactions.list(account=...)`.
2. Balance is the sum of integer cents; the count is the number of the account's transactions.
3. Write balances with exactly two decimals, a leading `-` when negative, and no thousands separator.
4. An empty ledger writes the header and `TOTAL,,0,0.00`.
5. The command is read-only.

## Database Interface

- None — persistence is owned by DATABASE.md.

## Programmatic Acceptance

# FEATURE: Report Categories

| Field | Value |
|-------|-------|
| Version | 20261027 V1 |
| Description | Implements `ledger report categories`, per-category transaction counts with inflow, outflow, and net computed from stored transactions. |
| Depends On | FEATURE-ReportBalances.md, FEATURE-LedgerCli.md, DATABASE.md |
| Provides | ledger report categories |
| Consumes | ledger, categories, transactions |

## Questions

- None.

## Purpose

Show how cash moved by category, including categories that have no transactions.

## Interface

`ledger report categories`

Standard output on success (exit 0):

- header `category,description,transactions,inflow,outflow,net`
- one row per category ordered by code ascending, including categories with no transactions
- final row `TOTAL,,<count>,<inflow>,<outflow>,<net>`

## Behavior

1. Read categories with `db.categories.list` and transactions with `db.transactions.list`.
2. `inflow` is the sum of positive amounts; `outflow` is the sum of the absolute values of negative amounts, written as a positive number; `net` is `inflow - outflow`.
3. All amounts are integer cents, written with exactly two decimals and no thousands separator.
4. The TOTAL count is the number of transactions; its inflow, outflow, and net are the column sums.
5. With no categories the output is the header and `TOTAL,,0,0.00,0.00,0.00`.
6. The command is read-only.

## Database Interface

- None — persistence is owned by DATABASE.md.

## Programmatic Acceptance

=== AC report-categories-rows ===
Intent: Each category row carries count, inflow, outflow, and net derived from the stored transactions, categories are ordered by code, a category without transactions still appears with zeros, and the TOTAL row sums the columns.

import csv
import io
import re
from decimal import Decimal
from cli.testing import cli_runner
from persistence.testing import db_session

acct = "ZQG0"
money = r"-?\d+\.\d{2}"
with db_session() as db:
    db.accounts.create(account=acct, name="Cat Account")
    db.categories.create(category="ZQG3", description="Third Category")
    db.categories.create(category="ZQG1", description="First Category")
    db.categories.create(category="ZQG2", description="Unused Category")
    base = max([r.txn_id for r in db.transactions.list()] or [0]) + 1
    db.transactions.create(txn_id=base, date="2026-06-01", account=acct, category="ZQG1", amount=100000, memo="")
    db.transactions.create(txn_id=base + 1, date="2026-06-02", account=acct, category="ZQG1", amount=25050, memo="")
    db.transactions.create(txn_id=base + 2, date="2026-06-03", account=acct, category="ZQG1", amount=-4000, memo="")
    db.transactions.create(txn_id=base + 3, date="2026-06-04", account=acct, category="ZQG3", amount=-10000, memo="")
    count_before = len(db.transactions.list())
    code, out, err = cli_runner("report", "categories")
    print(out)
    print(err)
    assert code == 0
    assert "\r" not in out
    rows = list(csv.reader(io.StringIO(out)))
    assert rows[0] == ["category", "description", "transactions", "inflow", "outflow", "net"]
    all_txns = db.transactions.list()
    expected = []
    for c in sorted(db.categories.list(), key=lambda r: r.category):
        mine = [t.amount for t in all_txns if t.category == c.category]
        inflow = sum(a for a in mine if a > 0)
        outflow = sum(-a for a in mine if a < 0)
        expected.append((c.category, c.description, len(mine), inflow, outflow))
    data = rows[1:-1]
    assert len(data) == len(expected)
    for row, (cat_code, desc, n, inflow, outflow) in zip(data, expected):
        assert row[0] == cat_code
        assert row[1] == desc
        assert int(row[2]) == n
        assert Decimal(row[3]) == Decimal(inflow).scaleb(-2)
        assert Decimal(row[4]) == Decimal(outflow).scaleb(-2)
        assert Decimal(row[5]) == Decimal(inflow - outflow).scaleb(-2)
        for cell in row[3:]:
            assert re.fullmatch(money, cell)
    codes = [r[0] for r in data]
    assert codes.index("ZQG1") < codes.index("ZQG2") < codes.index("ZQG3")

# FEATURE: Report Monthly

| Field | Value |
|-------|-------|
| Version | 20261027 V1 |
| Description | Implements `ledger report monthly`, per-month transaction counts with inflow, outflow, and net computed from stored transactions. |
| Depends On | FEATURE-ReportBalances.md, FEATURE-LedgerCli.md, DATABASE.md |
| Provides | ledger report monthly |
| Consumes | ledger, transactions |

## Questions

- None.

## Purpose

Show how cash moved month by month.

## Interface

`ledger report monthly`

Standard output on success (exit 0):

- header `month,transactions,inflow,outflow,net`
- one row per `YYYY-MM` that has at least one transaction, ascending
- final row `TOTAL,<count>,<inflow>,<outflow>,<net>`

## Behavior

1. Read transactions with `db.transactions.list` and group them by the first seven characters of `date`.
2. `inflow` is the sum of positive amounts; `outflow` the sum of absolute values of negative amounts, written positive; `net` is `inflow - outflow`.
3. All amounts are integer cents written with exactly two decimals and no thousands separator.
4. Months without transactions produce no row.
5. With no transactions the output is the header and `TOTAL,0,0.00,0.00,0.00`.
6. The command is read-only.

## Database Interface

- None — persistence is owned by DATABASE.md.

## Programmatic Acceptance

=== AC report-monthly-rows ===
Intent: Months are grouped from the stored transaction dates, listed ascending with count, inflow, outflow, and net, and the TOTAL row sums the columns; the fixtures are inserted out of date order and skip a month.

import csv
import io
import re
from decimal import Decimal
from cli.testing import cli_runner
from persistence.testing import db_session

acct = "ZQM1"
cat = "ZQM1"
with db_session() as db:
    db.accounts.create(account=acct, name="Month Account")
    db.categories.create(category=cat, description="Month Category")
    base = max([r.txn_id for r in db.transactions.list()] or [0]) + 1
    db.transactions.create(txn_id=base, date="2031-09-01", account=acct, category=cat, amount=30000, memo="")
    db.transactions.create(txn_id=base + 1, date="2031-07-31", account=acct, category=cat, amount=50025, memo="")
    db.transactions.create(txn_id=base + 2, date="2031-09-20", account=acct, category=cat, amount=-1250, memo="")
    db.transactions.create(txn_id=base + 3, date="2031-07-05", account=acct, category=cat, amount=-300, memo="")
    count_before = len(db.transactions.list())
    code, out, err = cli_runner("report", "monthly")
    print(out)
    print(err)
    assert code == 0
    assert "\r" not in out
    rows = list(csv.reader(io.StringIO(out)))
    assert rows[0] == ["month", "transactions", "inflow", "outflow", "net"]
    all_txns = db.transactions.list()
    months = sorted({t.date[:7] for t in all_txns})
    data = rows[1:-1]
    assert [r[0] for r in data] == months
    assert "2031-08" not in months
    total_n = total_in = total_out = 0
    for row, month in zip(data, months):
        mine = [t.amount for t in all_txns if t.date[:7] == month]
        inflow = sum(a for a in mine if a > 0)
        outflow = sum(-a for a in mine if a < 0)
        assert int(row[1]) == len(mine)
        assert Decimal(row[2]) == Decimal(inflow).scaleb(-2)
        assert Decimal(row[3]) == Decimal(outflow).scaleb(-2)
        assert Decimal(row[4]) == Decimal(inflow - outflow).scaleb(-2)
        for cell in row[2:]:
            assert re.fullmatch(r"-?\d+\.\d{2}", cell)
        total_n += len(mine)
        total_in += inflow
        total_out += outflow
    total = rows[-1]
    assert total[0] == "TOTAL"
    assert int(total[1]) == total_n == len(all_txns)
    assert Decimal(total[2]) == Decimal(total_in).scaleb(-2)
    assert Decimal(total[3]) == Decimal(total_out).scaleb(-2)
    assert Decimal(total[4]) == Decimal(total_in - total_out).scaleb(-2)
    assert len(db.transactions.list()) == count_before
