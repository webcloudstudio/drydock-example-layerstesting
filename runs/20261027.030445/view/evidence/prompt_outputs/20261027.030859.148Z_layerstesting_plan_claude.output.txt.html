## Persistence Boundary

| Boundary | Rule |
|----------|------|
| Raw storage access | Only the generated `persistence/` package reaches the store. |
| Caller dependency | Features depend on declared access patterns and their DTOs, not on schemas. |
| Implementation | Generated from this file at the DATABASE build step; never written by hand. |
| Money | Amounts are stored as integer cents; no floating point at any layer. |
| Aggregates | Balances, counts, and report totals are computed by callers in integer cents from `list` results; the store declares no aggregate operation. |
| Reset | `init` removes rows through the `delete_all` operations (transactions first, then categories and accounts); no DDL runs at runtime. |

from persistence.testing import db_session

acct_a = "ZQT5"
acct_b = "ZQT6"
cat = "ZQT5"
ids_a = [900013, 900011, 900012]
id_b = 900014
with db_session() as db:
    db.accounts.create(account=acct_a, name="Account A")
    db.accounts.create(account=acct_b, name="Account B")
    db.categories.create(category=cat, description="Txn Category")
    for i in ids_a:
        db.transactions.create(
            txn_id=i, date="2026-05-05", account=acct_a, category=cat, amount=100, memo=""
        )
    db.transactions.create(
        txn_id=id_b, date="2026-05-05", account=acct_b, category=cat, amount=100, memo=""
    )
    rows = db.transactions.list(account=acct_a)
    assert [r.txn_id for r in rows] == sorted(ids_a)
    assert all(r.account == acct_a for r in rows)
    everything = db.transactions.list()
    assert id_b in [r.txn_id for r in everything]
