## Purpose

This is the terminal story. Every command story has closed before it runs. It assembles the finished
application and proves two things from the application root: the supplied grader `sources/run.sh`
exits zero with all 43 checks passing, and the application's own `bin/test.sh` suite exits zero.

The grader is read-only input. It is never modified, filtered, skipped, or reinterpreted. It creates a
fresh temporary database unless the caller sets `DATABASE_URL`, runs `./ledger init`, loads the staged
seed files, and compares each command's exit code and standard output with its known answers. Standard
error is never compared.

## Assembly and Intent

- Run `sh sources/run.sh` unfiltered from the application root and require exit status 0.
- The grader reports `LayersTesting: <passed> passed, <failed> failed (of <total>)`; the source states
  43 checks, so the total is 43 and the failed count is 0.
- Run `sh bin/test.sh` and require exit status 0.
- `./ledger` exists at the application root with its executable bit set, because the grader tests `-x`.
- Nothing under `sources/` is altered, and application code never reads `sources/run.sh` or any seed
  file; seed files reach the database only through `ledger load`.

## Database Interface

- None — persistence is owned by DATABASE.md and reached by the command stories.

=== AC grader-full ===
Intent: The supplied grader run unfiltered exits zero with every one of its 43 checks passing.
Suite: full
Requires: executable=sh; scope=test

import os
import re
import subprocess
import sys

expected_total = 43
result = subprocess.run(
    ["sh", "sources/run.sh"],
    capture_output=True,
    text=True,
    env={**os.environ},
)
print(result.stdout)
print(result.stderr, file=sys.stderr)
lines = [ln for ln in result.stdout.splitlines() if ln.strip()]
match = re.match(r"^LayersTesting: (\d+) passed, (\d+) failed \(of (\d+)\)$", lines[-1]) if lines else None
if match:
    passed, failed, total = (int(g) for g in match.groups())
    print(f"{passed} passed, {failed} failed, {total} total")
    assert failed == 0
    assert total == expected_total
    assert passed == total
assert result.returncode == 0
=== END AC grader-full ===
