FEATURE: Txn Get

FieldValue
Version20261026 V1
DescriptionImplements ledger txn get <id>, which prints one stored transaction row.
Depends OnFEATURE-TxnPost.md, FEATURE-CsvOutput.md, FEATURE-CliFoundation.md, FEATURE-ErrorContract.md, DATABASE.md
Providesledger txn get
Consumesledger.register_command, persistence.open_database, csv_output.write_rows, ledger_errors.NotFound

Purpose

Read back a single transaction by id from stored data.

Behavior

  • Invocation: ledger txn get <id> with exactly one argument.
  • A non-integer id exits 3 (narrowest reading of the unspecified case, recorded as decision Q-003).
  • An integer id with no stored row exits 4 with nothing on stdout.
  • Otherwise the command writes the header txn_id,date,account,category,amount,memo and the stored row, with the amount formatted as exactly two decimals from integer cents.

Database Interface

  • FEATURE-TXN-002 — read: get the transaction by id - supplies: txn_id - returns: txn_id, date, account, category, amount, memo

Programmatic Acceptance

=== AC txn-get-present ===
Intent: Getting a stored transaction prints its current row with a two-decimal amount.

import csv import io from decimal import Decimal from cli.testing import cli_runner from persistence.testing import db_session

acct = "ZQGET1" cat = "ZQGETC1" txn_id = 920001 date = "2026-04-01" cents = -1234 memo = "read me" with db_session() as db: db.accounts.create(account=acct, name="Get Account") db.categories.create(category=cat, description="Get Category") db.transactions.create( txn_id=txn_id, date=date, account=acct, category=cat, amount=cents, memo=memo ) code, out, err = cli_runner("txn", "get", str(txn_id)) print(out) print(err) assert code == 0 rows = list(csv.reader(io.StringIO(out))) assert rows[0] == ["txn_id", "date", "account", "category", "amount", "memo"] shown = f"{Decimal(cents) / 100:.2f}" assert rows[1] == [str(txn_id), date, acct, cat, shown, memo] === END AC txn-get-present ===
