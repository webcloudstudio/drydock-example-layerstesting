FEATURE: Account Get

FieldValue
Version20261026 V1
DescriptionImplements ledger account get <code> printing an account with its transaction count and balance.
Depends OnARCHITECTURE.md, DATABASE.md, FEATURE-AccountAdd.md, FEATURE-CsvOutput.md, FEATURE-ErrorContract.md
Providesledger account get
Consumesledger.register_command, persistence.open_database, csv_output.write_rows, ledger_errors.NotFound

Purpose

ledger account get <code> prints the current account row, with the transaction count and balance computed from stored transactions at the time of the call.

Behavior

  • Argument: exactly one code; any other count is a usage error (exit 2).
  • Writes account,name,transactions,balance then the row. transactions is the number of the account's transactions; balance is the sum of their amounts in integer cents, written with exactly two decimals, a leading - when negative, and 0.00 for zero.
  • An absent code exits 4 with nothing on standard output.

Database Interface

  • FEATURE-ACCOUNT-002 — read: get an account by code - supplies: account - returns: account, name
  • FEATURE-TXN-003 — read: list the account's transactions to count and sum them - supplies: account - returns: txn_id, account, amount

Programmatic Acceptance

=== AC account-get-with-activity ===
Intent: The printed transaction count and balance are computed from the stored transactions.

import csv import io from decimal import Decimal from cli.testing import cli_runner from persistence.testing import db_session

acct, cat = "ZAG1A", "ZAG1C" name = "Get Account" amounts = [50000, -12550, 325] with db_session() as db: db.accounts.create(account=acct, name=name) db.categories.create(category=cat, description="Get test") for i, cents in enumerate(amounts): db.transactions.create( txn_id=920001 + i, date="2026-05-01", account=acct, category=cat, amount=cents, memo="" ) code, out, err = cli_runner("account", "get", acct) print(out, err) assert code == 0 balance = f"{Decimal(sum(amounts)).scaleb(-2):.2f}" assert list(csv.reader(io.StringIO(out))) == [ ["account", "name", "transactions", "balance"], [acct, name, str(len(amounts)), balance], ] === END AC account-get-with-activity ===

Guardrails
