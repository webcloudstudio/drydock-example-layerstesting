## Configuration

The database DSN is resolved in this order:

1. `DATABASE_URL`
2. `DATABASE_PATH`
3. `data/app.db`

A `postgres://` or `postgresql://` URL selects PostgreSQL. Other values select SQLite, with an optional `sqlite://` prefix.
