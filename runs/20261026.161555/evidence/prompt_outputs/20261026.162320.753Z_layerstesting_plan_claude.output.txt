## Persistence Boundary

| Boundary | Rule |
|----------|------|
| Raw storage access | Only the generated `persistence/` package reaches the store. |
| Caller dependency | Features depend on declared access patterns and their DTOs, not on schemas. |
| Implementation | Generated from this file at the DATABASE build step; never written by hand. |
| Money | Amounts are stored as integer cents and never as floating point. |
| Aggregation | Repository operations have no aggregates; services sum list results in integer cents. |

## Schemas

| Field | Type | Notes |

| account | VARCHAR(12) PK | Account code. |

| Field | Type | Notes |

## `transactions`

| Field | Type | Notes |
|-------|------|-------|
| txn_id | INTEGER PK | Transaction id. |
| date | TEXT NOT NULL | YYYY-MM-DD. |
| account | VARCHAR(12) NOT NULL REFERENCES accounts(account) | Owning account. |
| category | VARCHAR(12) NOT NULL REFERENCES categories(category) | Category. |
| amount | INTEGER NOT NULL | Signed integer cents. |
| memo | VARCHAR(60) NOT NULL DEFAULT '' | Memo text. |

            txn_id=i, date="2026-04-03", account=a1, category=cat, amount=100, memo=""

    everything = [f(r, "txn_id") for r in db.transactions.list()]
