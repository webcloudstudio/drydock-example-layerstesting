FEATURE: Load Transactions

FieldValue
Version20261025 V1
DescriptionImplements ledger load transactions <csv>, which loads transactions keeping their file ids, all-or-nothing.
Depends OnARCHITECTURE.md, DATABASE.md, FEATURE-CliEntry.md, FEATURE-LedgerCore.md, FEATURE-LoadAccounts.md, FEATURE-LoadCategories.md
Providesledger load transactions
Consumescli.main, parse_amount, validate_text, validate_date, balance_guard, ledger load accounts, ledger load categories

Purpose

Bulk-load transaction rows. Each loaded transaction keeps the txn_id written in its file. The command either stores every row or stores nothing.

Command Contract

ledger load transactions <csv> registers under the load command in the cli command table.

ConditionResult
File readable, header equals txn_id,date,account,category,amount,memo, every row valid, resulting balances non-negativeExit 0. Stdout is table,loaded then transactions,<rows>.
Missing <csv> argument or extra argumentsExit 2, nothing on stdout.
File missing or unreadableExit 1, nothing on stdout.
Header mismatch; non-integer txn_id; bad date, amount, or memoExit 3, nothing stored.
Unknown account or unknown categoryExit 3, nothing stored.
A txn_id repeats within the file or already exists in the tableExit 3, nothing stored.
Loading would leave any account balance below zeroExit 3, nothing stored.

Behavior

  1. Read the whole file with the standard csv module and check the header.
  2. For each row validate the id, the date (a real calendar date), the amount (-?DIGITS[.D[D]],

never zero, parsed to integer cents), the memo (0 to 60 characters, no comma or newline), and that the account and category exist.

  1. Reject repeated ids within the file and ids already stored.
  2. Compute each touched account's stored balance plus the file's amounts with balance_guard; any

result below zero rejects the file.

  1. Only after every check passes, write all rows in one transaction, then print the result.

Database Interface

  • FEATURE-ACCOUNT-002 — read: confirm every named account exists - supplies: account - returns: account, name
  • FEATURE-CATEGORY-002 — read: confirm every named category exists - supplies: category - returns: category, description
  • FEATURE-TXN-002 — read: read existing ids and balances - supplies: account, category - returns: txn_id, date, account, category, amount, memo

Rows are written through db.transactions.create, the operation declared for the post feature in DATABASE.md; this feature reuses it and declares no operation of its own.

import csv import io import os import tempfile from cli.testing import cli_runner from persistence.testing import db_session

def counts(): rc, out, err = cli_runner("count") assert rc == 0 return {r[0]: int(r[1]) for r in list(csv.reader(io.StringIO(out)))[1:]}

def load(table, header, rows, tmp): path = os.path.join(tmp, table + ".csv") with open(path, "w", newline="") as fh: w = csv.writer(fh, lineterminator="\n") w.writerow(header) w.writerows(rows) return cli_runner("load", table, path)

acct, cat = "LDTXA1", "LDTXC1" with db_session() as db: base = max([t.txn_id for t in db.transactions.list()], default=0) + 1000 ids = [base + 1, base + 2, base + 3] rows = [ [ids[0], "2026-05-01", acct, cat, "100.00", "deposit"], [ids[1], "2026-05-02", acct, cat, "-25.50", "payment"], [ids[2], "2026-05-03", acct, cat, "10.25", ""], ] with tempfile.TemporaryDirectory() as tmp: assert load("accounts", ["account", "name"], [[acct, "Load Txn Account"]], tmp)[0] == 0 assert load("categories", ["category", "description"], [[cat, "Load Txn Category"]], tmp)[0] == 0 before = counts() rc, out, err = load( "transactions", ["txn_id", "date", "account", "category", "amount", "memo"], rows, tmp ) print(out) print(err) assert rc == 0 parsed = list(csv.reader(io.StringIO(out))) assert parsed == [["table", "loaded"], ["transactions", str(len(rows))]] assert counts()["transactions"] == before["transactions"] + len(rows) cents = [10000, -2550, 1025] with db_session() as db: for row, c in zip(rows, cents): got = db.transactions.get(txn_id=row[0]) assert got is not None assert got.date == row[1] assert got.account == acct assert got.category == cat assert got.amount == c assert got.memo == row[5] === END AC load-transactions-valid ===

User Acceptance

  • None.

Guardrails

  • A loaded transaction keeps the txn_id from its file; no id is reassigned.
  • Amounts are parsed to integer cents; no floating point is used at any layer.
  • Every check, including the projected balances, completes before the first write.
  • Application code never reads sources/ seed files; the file path comes only from the command line.
