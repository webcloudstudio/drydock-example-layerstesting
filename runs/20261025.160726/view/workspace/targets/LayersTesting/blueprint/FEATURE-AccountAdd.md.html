FEATURE: Account Add

FieldValue
Version20261025 V1
DescriptionImplements ledger account add <code> <name>, which creates one validated account.
Depends OnARCHITECTURE.md, DATABASE.md, FEATURE-CliEntry.md, FEATURE-LedgerCore.md, FEATURE-Init.md, FEATURE-Count.md
Providesledger account add
Consumescli.main, format_amount, validate_code, validate_text

Purpose

Add a new place where the shop keeps cash. A new account has no transactions and a zero balance.

Command Contract

ledger account add <code> <name> registers under the account command in the cli command table.

ConditionResult
Valid code and name, code not in useExit 0. Stdout is account,name,transactions,balance then the new row with 0 transactions and balance 0.00.
Wrong argument countExit 2, nothing on stdout.
Code not 1 to 12 characters of A-Z0-9Exit 3, nothing stored.
Name empty, longer than 40 characters, or containing a comma or newlineExit 3, nothing stored.
Code already existsExit 3, nothing stored.

Behavior

  1. Validate the code and name with the ledger-core validators.
  2. Confirm the code is not already stored.
  3. Create the row, then print the account row. The transaction count and balance are computed from

the database, never hard-coded, and formatted from integer cents with two decimal places.

  1. A failing command writes one diagnostic line to standard error and nothing to standard output.

Database Interface

  • FEATURE-ACCOUNT-003 — write: create an account - supplies: account, name - returns: account, name
  • FEATURE-ACCOUNT-002 — read: detect an existing code - supplies: account - returns: account, name
  • FEATURE-TXN-002 — read: count the account's transactions and sum its balance - supplies: account - returns: txn_id, amount
