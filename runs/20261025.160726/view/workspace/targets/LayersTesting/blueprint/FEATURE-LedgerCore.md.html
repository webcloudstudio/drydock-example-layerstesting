FEATURE: Ledger Core

FieldValue
Version20261025 V1
DescriptionShared integer-cent amount parsing and formatting, field and date validators, and the projected-balance guard.
Depends OnARCHITECTURE.md, DATABASE.md, FEATURE-CliEntry.md
Providescli.core.parse_amount, cli.core.format_amount, cli.core.validate_code, cli.core.validate_text, cli.core.validate_name, cli.core.validate_memo, cli.core.validate_date, cli.core.account_balance, cli.core.balance_guard

Purpose

Every command shares the same input rules. They live in cli/core.py so that no command repeats or contradicts them. All validators raise cli.errors.Rejected (exit 3) and perform no database write.

Rules

FunctionContract
parse_amount(text) -> intAccepts only ASCII text matching -?DIGITS[.D[D]]. Returns integer cents using integer arithmetic only. Zero (such as 0, 0.00, -0.0) is rejected. More than two decimals, a missing integer part, a plus sign, spaces, or a thousands separator is rejected.
format_amount(cents) -> strExactly two decimals, a leading - when negative, no thousands separator. 0 prints as the zero amount with two decimals.
validate_code(text) -> str1 to 12 characters from A-Z and 0-9.
validate_text(text, min_len, max_len) -> strLength within bounds; no comma, \n, or \r.
validate_name(text)validate_text with 1 to 40 characters. Used for account names and category descriptions.
validate_memo(text)validate_text with 0 to 60 characters.
validate_date(text) -> strMatches YYYY-MM-DD with four-digit year, two-digit month and day, and is a real calendar date. A date such as the thirtieth of February is rejected.
account_balance(db, account) -> intSum of the account's transaction amounts, read with db.transactions.list(account=...). Zero when it has none.
balance_guard(db, deltas) -> Nonedeltas maps account code to a net change in cents. Computes each account's balance after applying its delta and raises Rejected when any resulting balance is below zero. It never writes.

Commands call balance_guard with the full change set before their first write. A load passes the summed delta per account for the whole file; a transfer passes both accounts; amend passes the new amount minus the old; delete passes the negated old amount.

Database Interface

  • None — persistence is owned by DATABASE.md, FEATURE-AccountAdd.md, FEATURE-AccountDelete.md, FEATURE-AccountGet.md, FEATURE-AccountRename.md, FEATURE-Init.md, FEATURE-TxnAmend.md, FEATURE-TxnDelete.md, FEATURE-TxnGet.md, FEATURE-TxnPost.md.
