Purpose

The terminal story. Once every other story has closed, it runs sh sources/run.sh from the application root without filtering and requires exit status zero. That exit status is the whole verdict. The grader creates its own temporary database, so the run must not share the configured application store.

Behavior

  • The assembled application provides an executable ledger at the application root.
  • sh sources/run.sh exits zero: all 43 checks pass.
  • Nothing under sources/ is modified to obtain that result.

Database Interface

  • None — persistence is owned by FEATURE-Init.md.

env = {k: v for k, v in os.environ.items() if k not in ("DATABASE_URL", "DATABASE_PATH")} result = subprocess.run( ["sh", "sources/run.sh"], capture_output=True, text=True, env=env, timeout=900, ) print(result.stdout) print(result.stderr) tally = re.findall(r"(\d+) passed, (\d+) failed", result.stdout) if tally: print("grader tally (passed, failed):", tally[-1]) assert result.returncode == 0 === END AC release-grader-passes ===
