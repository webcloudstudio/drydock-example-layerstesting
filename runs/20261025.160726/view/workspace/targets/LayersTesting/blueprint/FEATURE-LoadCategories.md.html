FEATURE: Load Categories

FieldValue
Version20261025 V1
DescriptionImplements ledger load categories <csv>, which loads categories from a CSV file all-or-nothing.
Depends OnARCHITECTURE.md, DATABASE.md, FEATURE-CliEntry.md, FEATURE-LedgerCore.md, FEATURE-Init.md, FEATURE-Count.md
Providesledger load categories
Consumescli.main, validate_code, validate_text

Purpose

Bulk-load category rows so transactions can be classified. The command either stores every row or stores nothing.

Command Contract

ledger load categories <csv> registers under the load command in the cli command table.

ConditionResult
File readable, header equals category,description, every row validExit 0. Stdout is table,loaded then categories,<rows>.
Missing <csv> argument or extra argumentsExit 2, nothing on stdout.
File missing or unreadableExit 1, nothing on stdout.
Header differs from the table columns in name or orderExit 3, nothing stored.
A row has an invalid code or descriptionExit 3, nothing stored.
A code repeats within the file or already exists in the tableExit 3, nothing stored.

Behavior

  1. Read the whole file with the standard csv module and check the header.
  2. Validate every row (code 1 to 12 characters of A-Z0-9; description 1 to 40 characters with no

comma or newline) and both duplicate rules before the first write.

  1. Write all rows in one transaction, then print the result.
  2. A failing command writes one diagnostic line to standard error and nothing to standard output.

Database Interface

  • FEATURE-CATEGORY-003 — write: create a category - supplies: category, description - returns: category, description
  • FEATURE-CATEGORY-002 — read: detect codes already stored - supplies: category - returns: category, description

Programmatic Acceptance

=== AC load-categories-valid ===
Intent: A valid categories file loads, reports the loaded count, and every row reads back.

import csv import io import os import tempfile from cli.testing import cli_runner from persistence.testing import db_session

def counts(): rc, out, err = cli_runner("count") assert rc == 0 return {r[0]: int(r[1]) for r in list(csv.reader(io.StringIO(out)))[1:]}

codes = ["LDCAT1", "LDCAT2", "LDCAT3", "LDCAT4"] with tempfile.TemporaryDirectory() as tmp: path = os.path.join(tmp, "categories.csv") with open(path, "w", newline="") as fh: w = csv.writer(fh, lineterminator="\n") w.writerow(["category", "description"]) w.writerows([[c, "Desc " + c] for c in codes]) before = counts() rc, out, err = cli_runner("load", "categories", path) print(out) print(err) assert rc == 0 rows = list(csv.reader(io.StringIO(out))) assert rows == [["table", "loaded"], ["categories", str(len(codes))]] assert counts()["categories"] == before["categories"] + len(codes) with db_session() as db: for c in codes: got = db.categories.get(category=c) assert got is not None assert got.description == "Desc " + c === END AC load-categories-valid ===

=== AC load-categories-duplicates ===
Intent: A code repeated inside the file, or already stored, is rejected with exit 3 and nothing is added.

import csv import io import os import tempfile from cli.testing import cli_runner

def counts(): rc, out, err = cli_runner("count") assert rc == 0 return {r[0]: int(r[1]) for r in list(csv.reader(io.StringIO(out)))[1:]}

def write(path, rows): with open(path, "w", newline="") as fh: w = csv.writer(fh, lineterminator="\n") w.writerow(["category", "description"]) w.writerows(rows)

with tempfile.TemporaryDirectory() as tmp: dup_file = os.path.join(tmp, "dup.csv") write(dup_file, [["LDCDP1", "One"], ["LDCDP1", "Two"]]) before = counts() rc, out, err = cli_runner("load", "categories", dup_file) print(out, err) assert rc == 3 assert out == "" assert counts() == before

once = os.path.join(tmp, "once.csv") write(once, [["LDCDP2", "Only"]]) rc, out, err = cli_runner("load", "categories", once) assert rc == 0 after_first = counts() rc, out, err = cli_runner("load", "categories", once) print(out, err) assert rc == 3 assert out == "" assert counts() == after_first === END AC load-categories-duplicates ===
