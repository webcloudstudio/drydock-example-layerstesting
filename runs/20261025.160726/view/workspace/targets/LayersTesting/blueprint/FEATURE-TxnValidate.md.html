FEATURE: Txn Validate

FieldValue
Version20261025 V1
DescriptionSpecifies the input validation ledger txn post applies to category, amount, and date before it writes anything.
Depends OnFEATURE-TxnPost.md, FEATURE-LedgerCore.md, DATABASE.md
Providestxn post validation
Consumesledger txn post, parse_amount, validate_date

Purpose

Guarantee that an invalid category, amount, or date given to ledger txn post is rejected with exit 3 before the first write, and that valid boundary inputs are accepted. Wiring lives in the post command; this specification owns the rules and their proof.

Rules

InputValidRejected with exit 3
CategoryA code present in categoriesAn unknown category
Amount-?DIGITS[.D[D]], never zero, so 12, 12.5, -12.50More than two decimals (1.234), 12., a leading +, non-numeric text, empty text, 0, 0.00, -0.00
DateA real calendar date written YYYY-MM-DD, including a leap day in a leap year2026-02-30, 2026-02-29, 2026-2-3, non-date text

A rejected post writes no row, prints nothing to standard output, writes one diagnostic line to standard error, and consumes no transaction id: the next successful post receives one more than the largest id present.

Database Interface

  • FEATURE-CATEGORY-001 — read: look up the category named on input - supplies: category - returns: category, description
  • FEATURE-ACCOUNT-002 — read: confirm the account exists - supplies: account - returns: account, name

from persistence.testing import db_session from cli.testing import cli_runner

=== AC txnvalidate-valid-boundaries ===
Intent: A one-decimal amount and a leap-day date are accepted and stored as integer cents.

from persistence.testing import db_session from cli.testing import cli_runner

with db_session() as db: acct = "TVACCT4" cat = "TVCAT4" leap_day = "2028-02-29" db.accounts.create(account=acct, name="Validate Valid") db.categories.create(category=cat, description="Validate Valid Category") base = max([t.txn_id for t in db.transactions.list()], default=0) code, out, err = cli_runner("txn", "post", acct, cat, "12.5", leap_day) print(out) print(err) assert code == 0 stored = db.transactions.get(txn_id=base + 1) assert stored is not None assert stored.amount == 1250 assert stored.date == leap_day === END AC txnvalidate-valid-boundaries ===

User Acceptance

  • None.

Guardrails

  • Every check completes before the first write; a rejected post changes no table.
  • Amounts are parsed to integer cents; no floating point at any layer.
  • Rejections use exit 3, never exit 1 or 2.
