Purpose

Provide a POSIX-compatible bin/test.sh that runs the complete pytest suite from the application root and returns success only when every project test passes.

Test Scope

The suite covers:

  • command dispatch and usage errors;
  • database initialization and configuration;
  • account and category loading;
  • transaction loading and atomic rejection;
  • account and transaction CRUD;
  • balance invariants and atomic transfers;
  • balance, category, and monthly reports;
  • validation boundaries and all documented exit codes.

The suite uses temporary databases and does not modify supplied sources.

Programmatic Acceptance

=== AC project-test-runner ===
Intent: The project test runner exists, is executable, and passes the automated suite. import os import subprocess

runner = "bin/test.sh" assert os.path.isfile(runner) assert os.access(runner, os.X_OK)

result = subprocess.run(["sh", runner], capture_output=True, text=True) print(result.stdout) print(result.stderr) assert result.returncode == 0

=== END AC project-test-runner ===

=== AC project-test-runner-is-repeatable ===

first = subprocess.run(["sh", "bin/test.sh"], capture_output=True, text=True) print(first.stdout) print(first.stderr) assert first.returncode == 0

second = subprocess.run(["sh", "bin/test.sh"], capture_output=True, text=True) print(second.stdout) print(second.stderr) assert second.returncode == 0

=== END AC project-test-runner-is-repeatable ===
