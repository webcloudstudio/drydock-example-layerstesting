FEATURE: Count Rows

FieldValue
Version20261020 V1
DescriptionProvide ledger count, which reports the row count of each ledger table.
Depends OnFEATURE-InitSchema.md, FEATURE-CliOutput.md, DATABASE.md
Providesledger count
Consumesdb.accounts.list, db.categories.list, db.transactions.list

Purpose

ledger count writes the row count of each ledger table as CSV. Each count is a query against the store. No count is stored, cached, or hardcoded.

Trigger

ledger count with no further arguments.

Sequence

  1. Resolve the database target and open the store.
  2. Count rows in accounts, then categories, then transactions, each by a query.
  3. Write the header and three rows, then exit 0.

Routes and Interfaces

  • ledger count: writes table,rows, then accounts,<n>, categories,<n>, transactions,<n>.
  • Exit 1 when the tables are missing, with nothing on standard output.

Reads and Writes

  • Reads: all rows of accounts, categories, and transactions, counted by query.
  • Writes: none.
