FEATURE: Initialize Schema

FieldValue
Version20261020 V1
DescriptionProvide ledger init, which drops and recreates the three ledger tables empty.
Depends OnFEATURE-DatabaseTarget.md, FEATURE-CommandTransaction.md, FEATURE-CliDispatch.md, FEATURE-CliOutput.md, DATABASE.md
Providesledger init
Consumesopen_database, db.accounts.list, db.categories.list, db.transactions.list

Purpose

ledger init resets the store. It drops accounts, categories, and transactions if they exist, recreates all three from the declared schema, and leaves them empty. It writes nothing to standard output and exits 0. It runs inside the command transaction, so a failure leaves the prior tables as they were.

A missing SQLite file is created empty by the first command that opens it. If a command then finds no ledger tables, it exits 1 and writes nothing to standard output. The no-tables failure is exercised by the commands that read the tables; this feature verifies init itself.

Trigger

ledger init with no further arguments. Usage errors (extra arguments) exit 2 under FEATURE-CliDispatch.md.

Sequence

  1. Resolve the database target through FEATURE-DatabaseTarget.md.
  2. Open the store with open_database.
  3. Drop each declared table if present.
  4. Create each declared table empty, using the generated schema.
  5. Commit. Write nothing.

Routes and Interfaces

  • ledger init: exit 0 on success, 1 when the database is unreachable.

Reads and Writes

  • Writes: drops and recreates accounts, categories, and transactions.
  • Reads: none beyond the table existence check.
