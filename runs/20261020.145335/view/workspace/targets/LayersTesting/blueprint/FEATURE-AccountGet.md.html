FEATURE: Account Get

FieldValue
Version20261020 V1
DescriptionGet one account with its transaction count and balance computed from the database.
Depends OnDATABASE.md, FEATURE-AccountAdd.md, FEATURE-ValidateText.md, FEATURE-CliDispatch.md, FEATURE-CliOutput.md, FEATURE-InitSchema.md
Providesledger account get
Consumesaccounts.get, transactions.list

Purpose

Writes the account row for one code. The transaction count and balance are computed by query from the stored transactions, never stored on the account.

Command

ledger account get <code>

Contract

  • On success, standard output is the header account,name,transactions,balance followed by one row

<code>,<name>,<count>,<balance>. balance is the signed sum of the account's transaction amounts in integer cents, written with exactly two decimals.

  • A code that is well formed but absent exits 4 and writes nothing to standard output.
  • A code that is malformed under FEATURE-ValidateText exits 3 and writes nothing to standard output.

Validation precedes the lookup.

  • The command is read-only. It changes no table.

Database Interface

  • FEATURE-LEDGER-002 — read: read the account row - supplies: account - returns: account, name

Programmatic Acceptance

Intent: A newly added account reads back with zero transactions and a balance of 0.00.
