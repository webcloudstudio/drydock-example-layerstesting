FEATURE: Load Categories

FieldValue
Version20261020 V1
DescriptionProvide ledger load categories <csv>, which loads every category row from a file or none.
Depends OnFEATURE-CommandTransaction.md, FEATURE-ValidateText.md, FEATURE-CliDispatch.md, FEATURE-CliOutput.md, FEATURE-InitSchema.md, DATABASE.md
Providesledger load categories
Consumesdb.categories.create, db.categories.get, db.categories.list

Purpose

ledger load categories <csv> reads a categories file and inserts every row into the categories table. The whole load runs in one command transaction: if any row is rejected, no row is stored.

Trigger

ledger load categories <path>.

Sequence

  1. Open the file. If it cannot be read, exit 1.
  2. Check the header is exactly category,description. If it is not, exit 3.
  3. Validate each row's code and description with the validators of FEATURE-ValidateText.md. An

invalid row, or a code repeated within the file or already present in the table, exits 3.

  1. Insert every row with db.categories.create, inside the command transaction.
  2. Write table,loaded then categories,<rows> and exit 0.

Routes and Interfaces

  • ledger load categories <csv>: exit 0 on success; 1 unreadable file; 2 wrong argument count;

3 rejected header or row, with nothing stored.

Reads and Writes

  • Writes: inserts the file's rows into categories, all or none.
  • Reads: categories for duplicate detection.

Intent: Loading the staged seed categories file exits 0 and stores exactly its data rows. import os import tempfile import pathlib

from cli.testing import cli_runner from persistence import open_database

work = tempfile.mkdtemp() os.environ["DATABASE_URL"] = os.path.join(work, "ledger.db") cli_runner("init")

seed = pathlib.Path("sources/seed_categories.csv") expected_rows = len(seed.read_text().splitlines()) - 1

expected_exit = 0 code, out, err = cli_runner("load", "categories", str(seed)) print("stdout:", repr(out), "stderr:", repr(err)) assert code == expected_exit lines = out.splitlines() assert lines[0] == "table,loaded" assert lines[1].split(",") == ["categories", str(expected_rows)]

db = open_database(os.environ["DATABASE_URL"]) assert len(db.categories.list()) == expected_rows === END AC load-categories-seed-file ===

User Acceptance

Guardrails

  • Loading is all or none; a rejected file leaves categories exactly as it was.
  • Row values are inserted as read; no total or derived field is written.
  • The seed file is read from the staged sources/ path and never embedded in application code.
