FEATURE: CLI Help

FieldValue
Version20261020 V1
DescriptionPrint usage and arguments for every command and sub-verb on --help, exiting 0.
Depends OnFEATURE-USAGE-ERRORS.md, FEATURE-SCHEMA-COUNT.md, FEATURE-ACCOUNT-DELETE.md, FEATURE-TXN-DELETE.md, FEATURE-TRANSFER-REJECTION.md, FEATURE-LOAD-HEADER.md, FEATURE-REPORT-MONTHLY.md
Providesledger <command> --help, ledger <command> <sub-verb> --help

Purpose

Every command and sub-verb of the ledger executable prints its usage and arguments when --help is given. The help output is written to standard output and the process exits 0. Help output is exempt from the CSV output rule in FEATURE-CSV-OUTPUT.md.

Behavior

  • --help may follow any command or sub-verb in the Commands table of sources/INSTRUCTIONS.md.
  • Help is printed before any argument validation. A command invoked with --help does not open the

database and does not change any row.

  • Help text is written to standard output only. Standard error stays empty.
  • The exit status is 0.

Commands and sub-verbs covered

CommandSub-verbs
init, count, load, transfernone
accountadd, get, rename, delete
txnpost, get, amend, delete
reportbalances, categories, monthly

User Acceptance

  • None.

Guardrails

  • --help never opens the database, never writes a row, and never drops or creates a table, including for init.
  • Help output is never written to standard error.
  • Help output does not follow the CSV output rule.
