Overview

The cash ledger is a local, single-user command-line program. Its executable is ledger at the application root. Every command reaches the database only through the generated persistence package, runs as one transaction, and writes CSV to standard output with diagnostics on standard error.

Technology Stack

  • Python 3.11 or newer: implementation language and pytest test runner (python.md).
  • SQLite: default database engine, reached through the persistence library (sqlite.md).
  • PostgreSQL: engine selected when DATABASE_URL is a postgres:// or postgresql:// DSN,

with psycopg[binary] as the driver (postgres.md). Variance: TECHNOLOGY_STACK.md does not list PostgreSQL, but sources/INSTRUCTIONS.md requires it. The sources govern, per decision Q-001.

  • CLI: the ledger executable (cli.md).
  • Shell: POSIX sh for bin/test.sh and the supplied grader (common.md).

Technical Decisions

  • Amounts are stored as integer cents. No layer uses floating point for money.
  • Every command runs as one database transaction through open_database(dsn).
  • pyproject.toml declares Python 3.11 or newer, pytest, and psycopg[binary]. uv.lock is

committed. .venv is created by uv venv.
