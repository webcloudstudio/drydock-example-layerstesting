FEATURE: Load Transactions

FieldValue
Version20261020 V1
DescriptionLoads transactions from a CSV file, keeping each file txn_id and applying the balance rule before commit.
Depends OnFEATURE-LOAD-ACCOUNTS.md, FEATURE-LOAD-CATEGORIES.md, FEATURE-NONNEGATIVE-BALANCE.md, FEATURE-VALIDATE-TEXT.md, FEATURE-VALIDATE-AMOUNT.md, FEATURE-VALIDATE-DATE.md, FEATURE-EXIT-CODES.md, FEATURE-TEST-RUNNER.md, DATABASE.md
Providesledger load transactions <csv>

Purpose

ledger load transactions <csv> reads a file whose header is txn_id,date,account,category,amount,memo, validates each row, and inserts every row with its file txn_id in one transaction. The balance rule is applied after all rows are written and before commit. Output is table,loaded then transactions,<rows>.

Database Interface

  • None — persistence is owned by DATABASE.md.

Programmatic Acceptance

=== AC load-transactions-keeps-file-ids ===
Intent: A valid transactions file loads every row under its file txn_id and writes table,loaded then transactions,<rows>.

import os import tempfile from cli.testing import cli_runner

work = tempfile.mkdtemp() os.environ["DATABASE_URL"] = os.path.join(work, "ledger.db") accounts = os.path.join(work, "accounts.csv") with open(accounts, "w") as handle: handle.write("account,name\nCASH1,Cash Box\n") categories = os.path.join(work, "categories.csv") with open(categories, "w") as handle: handle.write("category,description\nSALES,Sales receipts\n") transactions = os.path.join(work, "transactions.csv") with open(transactions, "w") as handle: handle.write( "txn_id,date,account,category,amount,memo\n" "7,2026-01-02,CASH1,SALES,10.00,sale a\n" "8,2026-01-03,CASH1,SALES,-4.00,refund\n" ) row_count = 2 file_id = 7 amount_text = "10.00"

assert cli_runner("init")[0] == 0 assert cli_runner("load", "accounts", accounts)[0] == 0 assert cli_runner("load", "categories", categories)[0] == 0 code, out, err = cli_runner("load", "transactions", transactions) assert code == 0 lines = out.splitlines() assert lines[0] == "table,loaded" assert lines[1].split(",") == ["transactions", str(row_count)] code, out, err = cli_runner("txn", "get", str(file_id)) assert code == 0 row = out.splitlines()[1].split(",") assert row[0] == str(file_id) assert row[4] == amount_text assert cli_runner("txn", "get", "8")[0] == 0 === END AC load-transactions-keeps-file-ids ===

User Acceptance

  • None.

Guardrails

  • Every row keeps its file txn_id; the loader never reassigns ids.
  • The balance rule is evaluated after the file's rows are staged and before commit, never per row.
  • Amounts are stored as integer cents and never pass through floating point.
