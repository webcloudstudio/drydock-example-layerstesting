FEATURE: Load Categories

FieldValue
Version20261020 V1
DescriptionLoads categories from a CSV file, validating every row before commit.
Depends OnFEATURE-NONNEGATIVE-BALANCE.md, FEATURE-VALIDATE-CODE.md, FEATURE-VALIDATE-TEXT.md, FEATURE-EXIT-CODES.md, FEATURE-TEST-RUNNER.md, DATABASE.md
Providesledger load categories <csv>

Purpose

ledger load categories <csv> reads a file whose header is category,description, validates each row's code and description, and inserts every row in one transaction. Output is table,loaded then categories,<rows>. A row that fails validation or duplicates an existing key rejects the whole file with exit 3.

Database Interface

  • FEATURE-CATEGORY-001 — write: create a category from a loaded row - supplies: category, description - returns: category, description

Programmatic Acceptance

=== AC load-categories-valid-file ===
Intent: A valid categories file loads every row and writes table,loaded then categories,<rows>.

import os import tempfile from cli.testing import cli_runner

work = tempfile.mkdtemp() os.environ["DATABASE_URL"] = os.path.join(work, "ledger.db") categories = os.path.join(work, "categories.csv") with open(categories, "w") as handle: handle.write("category,description\nSALES,Sales receipts\nRENT,Rent\n") row_count = 2

assert cli_runner("init")[0] == 0 code, out, err = cli_runner("load", "categories", categories) assert code == 0 lines = out.splitlines() assert lines[0] == "table,loaded" assert lines[1].split(",") == ["categories", str(row_count)] assert cli_runner("count")[1].splitlines()[2].split(",") == ["categories", str(row_count)] === END AC load-categories-valid-file ===
