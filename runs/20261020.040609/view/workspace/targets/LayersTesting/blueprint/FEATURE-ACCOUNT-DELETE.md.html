FEATURE: Account Delete

FieldValue
Version20261020 V1
DescriptionDelete an account that has no transactions through ledger account delete <code>.
Depends OnDATABASE.md, FEATURE-ACCOUNT-RENAME.md, FEATURE-NONNEGATIVE-BALANCE.md
Providesledger account delete
Consumesaccounts.get, transactions.list, accounts.delete

Purpose

ledger account delete <code> removes an account that no transaction references. An account that still has transactions is never removed, and no transaction is changed or removed to make room.

Behavior

  • Validate <code> with the code rule: 1 to 12 characters from A-Z and 0-9. An invalid code

exits 3.

  • Read the account. An absent code exits 4 and writes nothing.
  • Read the transactions. If any transaction names the account, exit 3 and change nothing.
  • Otherwise delete the account row inside the command's transaction, commit, then write the header

deleted and the code.

  • On any failure, write nothing to standard output and one diagnostic line to standard error.

Database Interface

  • None — persistence is owned by DATABASE.md.

Programmatic Acceptance

=== AC account-delete-removes ===
Intent: Deleting an account with no transactions exits 0, writes deleted then the code, and removes the account row.

import os import tempfile

from cli.testing import cli_runner from persistence.testing import db_session

dsn = os.path.join(tempfile.mkdtemp(), "ledger.db") os.environ["DATABASE_URL"] = dsn account_code = "CASH9" with db_session(dsn) as db: db.accounts.create(account=account_code, name="Event Float")

exit_code, out, err = cli_runner("account", "delete", account_code) print(out) print(err) assert exit_code == 0 assert out.splitlines() == ["deleted", account_code] with db_session(dsn) as db: assert account_code not in [row.account for row in db.accounts.list()] === END AC account-delete-removes ===

User Acceptance

  • None.

Guardrails

  • A transaction is never deleted, moved, or reassigned to allow an account deletion.
  • An account is never deleted while any transaction names it.
  • The deletion writes no output other than the deleted header and the code.
