FEATURE: Load Accounts

FieldValue
Version20261020 V1
DescriptionLoads accounts from a CSV file, validating every row before commit.
Depends OnFEATURE-NONNEGATIVE-BALANCE.md, FEATURE-VALIDATE-CODE.md, FEATURE-VALIDATE-TEXT.md, FEATURE-EXIT-CODES.md, FEATURE-TEST-RUNNER.md, DATABASE.md
Providesledger load accounts <csv>

Purpose

ledger load accounts <csv> reads a file whose header is account,name, validates each row's code and name, and inserts every row in one transaction. Output is table,loaded then accounts,<rows>. A row that fails validation or duplicates an existing key rejects the whole file with exit 3.

Database Interface

  • FEATURE-ACCOUNT-001 — write: create an account from a loaded row - supplies: account, name - returns: account, name

Programmatic Acceptance

=== AC load-accounts-valid-file ===
Intent: A valid accounts file loads every row and writes table,loaded then accounts,<rows>.

import os import tempfile from cli.testing import cli_runner

work = tempfile.mkdtemp() os.environ["DATABASE_URL"] = os.path.join(work, "ledger.db") accounts = os.path.join(work, "accounts.csv") with open(accounts, "w") as handle: handle.write("account,name\nDRAWER1,Front Drawer\nSAFE,Store Safe\n") row_count = 2

assert cli_runner("init")[0] == 0 code, out, err = cli_runner("load", "accounts", accounts) assert code == 0 lines = out.splitlines() assert lines[0] == "table,loaded" assert lines[1].split(",") == ["accounts", str(row_count)] assert cli_runner("count")[1].splitlines()[1].split(",") == ["accounts", str(row_count)] === END AC load-accounts-valid-file ===
