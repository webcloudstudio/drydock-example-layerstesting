FEATURE: Non-Negative Balance

FieldValue
Version20261020 V1
DescriptionRejects any command that would leave an account balance below zero, checked before commit.
Depends OnFEATURE-ATOMIC-COMMANDS.md, FEATURE-AMOUNT-CENTS.md, FEATURE-EXIT-CODES.md, DATABASE.md

Purpose

After a command's changes and before commit, sums each account's transaction amounts in integer cents. Any account whose balance is below zero causes the command to roll back and exit 3. Balance is the sum of transaction amounts; a balance of exactly zero is allowed.

Database Interface

  • None — persistence is owned by DATABASE.md.

Guardrails

  • Balances are computed in integer cents from stored rows, never from floating point.
  • A rejected balance check always rolls back the whole command; no partial change persists.
