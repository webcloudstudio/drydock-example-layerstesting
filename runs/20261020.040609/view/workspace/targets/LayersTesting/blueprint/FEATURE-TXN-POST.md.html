FEATURE: Transaction Post

FieldValue
Version20261020 V1
DescriptionPost a new cash transaction through ledger txn post, assigning the next transaction id.
Depends OnDATABASE.md, FEATURE-ACCOUNT-ADD.md, FEATURE-LOAD-CATEGORIES.md, FEATURE-NONNEGATIVE-BALANCE.md, FEATURE-VALIDATE-CODE.md, FEATURE-VALIDATE-TEXT.md, FEATURE-VALIDATE-AMOUNT.md, FEATURE-VALIDATE-DATE.md
Providesledger txn post
Consumesaccounts.get, categories.get, transactions.list, transactions.create

Purpose

ledger txn post <account> <category> <amount> <date> [<memo>] records one receipt or payment against an existing account and category. The command assigns the transaction id; the caller never supplies it.

Behavior

  • Validate the account and category codes, the amount, the date, and the memo. The memo is optional

and holds 0 to 60 characters with no comma or newline. Any violation exits 3.

  • Read the account and the category. An unknown account or category exits 3.
  • Read the largest existing txn_id. The new id is one more than that, or 1 when the table is

empty.

  • Insert the row, check that no account balance is below zero, then commit.
  • On success, write the header txn_id,date,account,category,amount,memo and the new row. Amounts

are written with exactly two decimal places.

Database Interface

  • None — persistence is owned by DATABASE.md.

Programmatic Acceptance

=== AC txn-post-round-trip ===
Intent: Posting a transaction exits 0, writes the header and the new row, and persists the row with integer cents.

import os import tempfile

from cli.testing import cli_runner from persistence.testing import db_session

dsn = os.path.join(tempfile.mkdtemp(), "ledger.db") os.environ["DATABASE_URL"] = dsn account_code = "CASH1" category_code = "SALES" with db_session(dsn) as db: db.accounts.create(account=account_code, name="Cash One") db.categories.create(category=category_code, description="Sales receipts") amount_text = "45.50" amount_cents = 4550 date_value = "2026-04-01" memo_value = "walk in sale"

exit_code, out, err = cli_runner( "txn", "post", account_code, category_code, amount_text, date_value, memo_value ) print(out) print(err) assert exit_code == 0 lines = out.splitlines() assert lines[0] == "txn_id,date,account,category,amount,memo" new_id = int(lines[1].split(",")[0]) with db_session(dsn) as db: row = db.transactions.get(txn_id=new_id) assert row.txn_id == new_id assert row.account == account_code assert row.category == category_code assert row.amount == amount_cents assert row.memo == memo_value === END AC txn-post-round-trip ===

Intent: An unknown account or an unknown category exits 3 and leaves the transaction count unchanged.

User Acceptance

  • None.

Guardrails

  • A caller never supplies a txn_id to txn post; the command assigns it.
  • A posted amount of zero is never stored.
  • A post that leaves any account balance below zero is never committed.
